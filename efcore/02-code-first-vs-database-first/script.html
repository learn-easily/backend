1Code First vs Database First

⏱ 0:00 · 2 წთ
სლაიდი ღიაა, სანამ სტუდენტები სხდებიან.
გამარჯობა! მე თქვენთან ორ ლექციას ჩავატარებ. EF Core-ით უკვე გიმუშავიათ: Entity-ები, DbContext, მიგრაციები, კავშირები.
ამ ორ ლექციაზე იმას, რასაც აქამდე აკეთებდით, სახელს დავარქმევთ — და ვნახავთ მეორე გზასაც.
დღეს ერთ მნიშვნელოვან კითხვას ვუპასუხებთ: ვინ არის მთავარი — ჩვენი კოდი თუ ბაზა?
მარჯვნივ ორი ისარი ხედავთ: ზედა მიდის კოდიდან ბაზისკენ — ეს Code First-ია. ქვედა მიდის ბაზიდან კოდისკენ — ეს Database First-ია.
დღეს ორივეს გავიგებთ და შევადარებთ, პრაქტიკაში კი Code First-ს გავაკეთებთ: როგორ იზრდება ბაზა კოდთან ერთად. მეორე ლექციაზე — Database First-ის პრაქტიკა.

→ 1Code First
შეხედეთ თანმიმდევრობას: ჯერ C#-ის კლასს წერთ, ბაზას კი EF Core ქმნის. SSMS-ში CREATE TABLE არ გიწერიათ. ამ გზას სახელი აქვს — Code First, „ჯერ კოდი“. თქვენ მას უკვე იყენებდით, უბრალოდ ასე არ გიწოდებიათ.
→ 2კითხვა
ახლა წარმოიდგინეთ: სამსახურში მიხვედით და ბაზა უკვე არსებობს — 300 ცხრილი, მილიონობით ჩანაწერი. ხომ არ დავწერთ 300 კლასს ხელით? ამაზეა დღევანდელი პირველი ნაწილი.

7ბაზიდან იბადება კოდი

⏱ 0:13 · 4 წთ
ახლა საპირისპირო გზა — Database First.
→ 1ბაზა
აქ ყველაფერი ბაზით იწყება. ის უკვე არსებობს: SSMS-ში CREATE TABLE-ით შექმნა ვიღაცამ — შეიძლება ჩვენ, შეიძლება DBA-მ, შეიძლება 10 წლის წინ.
→ 2Scaffold
ერთი ბრძანება — Scaffold-DbContext. EF Core უერთდება ბაზას, კითხულობს ყველა ცხრილს და თითოეულისთვის C#-ის კლასს წერს. DbContext-საც თვითონ წერს.
❓ 300 ცხრილი — რამდენ წამში? (წამებში, ხელით კი კვირები.)
→ 3ციკლი
ბაზა შეიცვალა — ცვლილებას ჯერ ბაზაში ვაკეთებთ (ALTER TABLE), მერე Scaffold-ს თავიდან ვუშვებთ -Force-ით, რომ კლასები განახლდეს.
→ 4ბრძანება
ასე გამოიყურება ბრძანება: connection string, პროვაიდერი SqlServer და ფოლდერი, სადაც კლასები ჩაიწერება. ! დეტალურად შემდეგ ლექციაზე გავაკეთებთ — დღეს მხოლოდ იდეა.
PMC-ში Scaffold-DbContext-ისთვის Tools და Design პაკეტებია საჭირო — იგივე, რაც მიგრაციებისთვის.

11Code First vs Database First

⏱ 0:24 · 5 წთ · ~ ყოველ ხაზზე ჯერ კითხე სტუდენტებს, მერე → გამოაჩინე
❓ სანამ ხაზებს გამოვაჩენ — თქვენ თქვით. ყოველ ხაზზე ჯერ თქვენ პასუხობთ.
→ 1წყარო
ჭეშმარიტების წყარო: Code First — კლასები, Database First — ბაზა. ეს უკვე ვიცით.
→ 2პირველი ნაბიჯი
Code First-ში ცარიელი ფურცლიდან ვიწყებთ კლასით. Database First-ში ბაზა უკვე მზადაა.
→ 3ცვლილება
ცვლილება: Code First — კლასი და ორი ბრძანება. Database First — ჯერ SQL ბაზაში, მერე Scaffold.
→ 4ისტორია
ისტორია — ძალიან მნიშვნელოვანია. Code First-ში ყოველი ცვლილება მიგრაციის ფაილია, Git-ში ინახება. ნებისმიერ დროს ვიცით, ბაზა როგორ შეიცვალა და შეგვიძლია უკან დავბრუნდეთ. Database First-ში ეს ისტორია EF-ის მიღმაა.
→ 5ვინ მართავს
Code First-ში ბაზას დეველოპერი მართავს კოდით. Database First ხშირად იქაა, სადაც ბაზას DBA მართავს — დეველოპერს ცხრილის შექმნის უფლებაც კი არ აქვს.
→ 6ტიპური პროექტი
ახალი პროექტი — Code First. ძველი, დიდი ბაზა — Database First.
→ 7ბრძანება
და მთავარი ბრძანებები: Add-Migration და Scaffold-DbContext.

Code First-ის პლიუსები: ყველაფერი C#-შია. ისტორია Git-ში. ახალი გუნდის წევრი მოვიდა — Update-Database და მას იგივე ბაზა აქვს.
