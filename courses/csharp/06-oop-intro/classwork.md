# დავალებები — აირჩიე დონე

Arena პროექტში, Hero კლასით

## ნაბიჯები

- ⭐ **გმირების სია** — `Hero[]` 4 გმირით: დაბეჭდე ყველა და გუნდის ჯამური სიცოცხლე
- ⭐⭐ **ხაფანგი** — დაწერე `static void Trap(Hero hero)`, რომელიც გმირს 25-ს აკლებს. გამოიძახე `Trap(team[0])` და დაბეჭდე `team[0].Health` — რატომ შეიცვალა?
- ⭐⭐ **ორი ცვლადი — ერთი გმირი** — `Hero a = team[1]; Hero b = a; b.TakeDamage(50);` → დაბეჭდე `a.Health` და ახსენი, რატომ შემცირდა

## ✓ მზადაა, როცა

ჯამური სიცოცხლე სწორია; `Trap`-ის შემდეგ პირველ გმირს 25-ით ნაკლები აქვს; შეგიძლია ახსნა, რატომ ცვლის `b` გმირს `a`-საც

## ⭐ ბონუსი

- ⭐⭐⭐ **ტურნირი** — `team`-ის ყოველი გმირი რიგრიგობით ებრძვის დრაკონს (ყოველ ჯერზე **ახალი** დრაკონი, 120 სიცოცხლით). ბოლოს დაბეჭდე, რამდენმა გმირმა მოიგო

## 💡 მინიშნება

ჯამი — `int total = 0;` და `foreach`-ში `total += h.Health;`. `Trap` გმირის **მისამართს** იღებს — ამიტომ ნამდვილ გმირს აზიანებს. ტურნირში დრაკონი ციკლის შიგნით შექმენი: `Hero dragon = new Hero("დრაკონი", 120);`.
