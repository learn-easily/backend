# დავალებები — აირჩიე დონე

მოსწავლეების მასივი და Arena-ს გმირი

## ნაბიჯები

- ⭐ **კლასის სტატისტიკა** — `Student[]` 4 მოსწავლით: დაბეჭდე მხოლოდ 16+ წლისები და მთელი კლასის საშუალო ქულა
- ⭐⭐ **ხაფანგი** — დაწერე `static void Trap(Hero hero)`, რომელიც გმირს 25-ს აკლებს. გამოიძახე `Trap(knight)` და დაბეჭდე `knight.Health` — რატომ შეიცვალა?
- ⭐⭐ **ორი ცვლადი — ერთი გმირი** — `Hero b = knight; b.TakeDamage(50);` → დაბეჭდე `knight.Health` და ახსენი, რატომ შემცირდა

## ✓ მზადაა, როცა

საშუალო სწორია და 16-ზე უმცროსი არ იბეჭდება; `Trap`-ის შემდეგ რაინდს 25-ით ნაკლები აქვს; შეგიძლია ახსნა, რატომ ცვლის `b` რაინდსაც

## ⭐ ბონუსი

- ⭐⭐⭐ **საუკეთესო და უარესი** — `Student[]`-ში ერთი ციკლით იპოვე ყველაზე მაღალი და ყველაზე დაბალი საშუალოს მქონე მოსწავლე

## 💡 მინიშნება

საშუალო — `double sum = 0;`, ციკლში `sum += s.Average;`, ბოლოს `sum / students.Length`. `Trap` გმირის **მისამართს** იღებს — ამიტომ ნამდვილ რაინდს აზიანებს. `Hero b = knight;` ახალ გმირს არ ქმნის.
