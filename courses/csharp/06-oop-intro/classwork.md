# დავალებები — აირჩიე დონე

Arena-ს ბრძოლა — ობიექტს მეთოდს ვაწვდით (მისამართით)

## ნაბიჯები

- ⭐ **ხაფანგი** — დაწერე `static void Trap(Hero hero)`: გმირს 15-ს აკლებს და ბეჭდავს „🪤 {Name} ხაფანგში გაება“. ბრძოლის ციკლში ყოველ მე-3 რაუნდში: `if (round % 3 == 0) Trap(knight);`
- ⭐⭐ **რაუნდის დაბეჭდვა** — დაწერე `static void PrintRound(int round, Hero a, Hero b)` და ციკლის დასაწყისში `Console.WriteLine($"── რაუნდი …")` ამით ჩაანაცვლე
- ⭐⭐ **გამარჯვებული** — დაწერე `static Hero Winner(Hero a, Hero b)`, რომელიც ცოცხალ გმირს აბრუნებს. ბრძოლის ბოლო ხაზი: `Console.WriteLine($"🏆 {Winner(knight, dragon).Name} გაიმარჯვა!");`

## ✓ მზადაა, როცა

ყოველ მე-3 რაუნდში რაინდს 15 აკლდება; `Main`-ში რაუნდის ბეჭდვა და გამარჯვებულის ternary აღარ არის — მეთოდები აკეთებენ; შეგიძლია ახსნა, რატომ ცვლის `Trap` ნამდვილ რაინდს და არა ასლს

## ⭐ ბონუსი

- ⭐⭐⭐ **ვინ გაება?** — ხაფანგი შემთხვევით ირჩევს: `Trap(Random.Shared.Next(2) == 0 ? knight : dragon);` — დრაკონიც შეიძლება გაებას. რომელი ობიექტი დაზიანდა და რატომ?

## 💡 მინიშნება

`Trap` გმირის **მისამართს** იღებს — ამიტომ ნამდვილ რაინდს აზიანებს. `Winner`-იც მისამართს აბრუნებს: `if (a.IsAlive()) return a; return b;`. ხაფანგმაც შეიძლება მოკლას გმირი — `while` ამას თავისით შეამოწმებს.
