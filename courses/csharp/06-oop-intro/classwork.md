# დავალებები — აირჩიე დონე

Arena-ს გმირი და ობიექტის მისამართი

## ნაბიჯები

- ⭐ **ორი გმირი** — შექმენი `knight` და `mage` (სხვადასხვა სიცოცხლით). თითოეული ერთხელ შეუტიოს მეორეს და დაბეჭდე ორივეს `Health`
- ⭐⭐ **ხაფანგი** — დაწერე `static void Trap(Hero hero)`, რომელიც გმირს 25-ს აკლებს. გამოიძახე `Trap(knight)` და დაბეჭდე `knight.Health` — რატომ შეიცვალა?
- ⭐⭐ **ორი ცვლადი — ერთი გმირი** — `Hero b = knight; b.TakeDamage(50);` → დაბეჭდე `knight.Health` და ახსენი, რატომ შემცირდა

## ✓ მზადაა, როცა

ორივე გმირის სიცოცხლე შეტევის შემდეგ შემცირდა; `Trap`-ის შემდეგ რაინდს 25-ით ნაკლები აქვს; შეგიძლია ახსნა, რატომ ცვლის `b` რაინდსაც

## ⭐ ბონუსი

- ⭐⭐⭐ **ძლიერი გმირი** — დაწერე `static Hero Stronger(Hero a, Hero b)`, რომელიც მეტი სიცოცხლის მქონე გმირს აბრუნებს. `Stronger(knight, mage).TakeDamage(10);` — რომელი გმირი დაზიანდა და რატომ?

## 💡 მინიშნება

`Trap` გმირის **მისამართს** იღებს — ამიტომ ნამდვილ რაინდს აზიანებს. `Hero b = knight;` ახალ გმირს არ ქმნის. `Stronger`-იც მისამართს აბრუნებს — დაზიანდება ნამდვილი გმირი, ასლი კი არა.
