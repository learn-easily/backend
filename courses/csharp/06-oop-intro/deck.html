### 💡 value და reference: ცვლადში ობიექტი კი არა, მისამართი წერია - **value type** — `int`, `double`, `bool`: ცვლადში თვითონ მნიშვნელობა წერია. `y = x` მას აკოპირებს — ორი დამოუკიდებელი რიცხვი. - **reference type** — კლასის ობიექტი (`Student`, `string`, მასივი…): ობიექტი მეხსიერებაში ცალკე ცხოვრობს, ცვლადში კი მხოლოდ მისი **მისამართი** (reference) წერია. `b = a` ისარს აკოპირებს — ახლა ორი ისარი ერთ ობიექტზე მიუთითებს. - ახალი ობიექტი მხოლოდ `new`-ით იქმნება. ცხოვრებიდან: მეგობარს სახლის **მისამართი** მიეცი. ორივეს ერთი მისამართი გაქვთ — მან სახლი რომ შეღებოს, შენც შეღებილს ნახავ. ```terms value type — ცვლადში თვითონ მნიშვნელობაა (int, double, bool) reference type — ცვლადში ობიექტის მისამართია (კლასები, string, მასივები) reference — მისამართი, რომლითაც ცვლადი ობიექტს „პოულობს“ ```
