**პრობლემა:** ერთი მეთოდი ბევრ სხვადასხვა რამეს უნდა აკეთებდეს — ქცევა გარედან უნდა გადავცეთ. **თემები:** დელეგატი; `Func`, `Action`, `Predicate`; lambda; მეთოდის გადაცემა პარამეტრად.

### 14. static, enum, struct და მეხსიერება

**პრობლემა:** ზოგი რამ ობიექტს კი არა, მთელ კლასს ეკუთვნის; ტექსტური სტატუსები (`"pending"`) შეცდომებს იწვევს. **თემები:** `static` ველი, მეთოდი, კლასი; `enum`; `namespace`; `struct` vs `class`; value vs reference ტიპი, stack და heap, GC მოკლედ. **Shop:** პროექტის დაწყება.

📚 გამოიყენებს `static`-ს და `enum`-ს
📚 აუხსნის value და reference ტიპის განსხვავებას მეხსიერებაში
📚 დაალაგებს პროექტს namespace-ებით
🛠 Shop | კონსოლის პროექტი `Shop`, `Product`, `Category` (enum), `OrderStatus` (enum)
