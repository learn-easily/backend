# საკუთარი თავგადასავალი

სიუჟეტი შენზეა — სტრუქტურა ჩვენზე

## მოთხოვნები

- ახალი Console App: **MyAdventure**. შენი სიუჟეტი (კოსმოსი, ზომბები, ფეხბურთის ფინალი — რაც გინდა)
- მინიმუმ **2 დონის** არჩევანი: პირველ არჩევანს მოსდევს მეორე (ჩადგმული `if`)
- მინიმუმ **4 სხვადასხვა დასასრული**
- გამოიყენე სამივე: `if / else if / else`, `switch` ან switch expression, და `? :`
- არასწორ პასუხზე („5“ ან „ბანანი“) პროგრამა გასაგებ შეტყობინებას ბეჭდავს — ბოლო `else` ან `_`
- თამაშის ბოლოს — ქულა: მოგება = 100, წაგება = 0, `$"…"`-ით დაბეჭდილი

## ✓ მზადაა, როცა

ყველა დასასრული გაიარე და თითოეული სწორად იბეჭდება; არასწორ შეყვანაზე პროგრამა არ ჩავარდა

## ⭐ ბონუსი

- დაამატე „ინვენტარი“: თამაშის დასაწყისში ჰკითხე, რას იღებს თან (ფანარი / ხმალი / რუკა), და ეს მოგვიანებით შედეგს ცვლის

## ამოხსნა

```csharp Program.cs · ერთი შესაძლო ვერსია !
Console.OutputEncoding = System.Text.Encoding.UTF8;
Console.Write("🚀 უცნობ პლანეტაზე დაეშვი. 1 — გასვლა · 2 — სიგნალი: ");
string first = Console.ReadLine();
string ending = "1 ან 2 უნდა აგერჩია 🤔";
int score = 0;

if (first == "1")
{
    Console.Write("👽 უცხოპლანეტელი! 1 — მისალმება · 2 — გაქცევა: ");
    bool friendly = Console.ReadLine() == "1";
    ending = friendly ? "🤝 მეგობარი შეიძინე!" : "🏃 ხომალდამდე ვერ მიაღწიე...";
    score = friendly ? 100 : 0;
}
else if (first == "2")
{
    Console.Write("📡 რა სიხშირეზე? (1-3): ");
    string freq = Console.ReadLine();
    ending = freq switch
    {
        "1" => "🛰️ დედამიწამ გიპასუხა — გადარჩი!",
        "2" or "3" => "🌑 პასუხი არავინ გაგცა...",
        _ => "❓ ასეთი სიხშირე არ არსებობს"
    };
    score = freq == "1" ? 100 : 0;
}

Console.WriteLine($"{ending} · ქულა: {score}");
```

```note
`bool friendly = Console.ReadLine() == "1";` — ჯერ `ReadLine` სრულდება, მერე შედარება (`==`) bool-ს აბრუნებს, ბოლოს `=` მას ცვლადში დებს. `ending`-ს დასაწყისშივე ვაძლევთ „არასწორი არჩევანის“ ტექსტს — თუ არც 1 იყო და არც 2, ის დარჩება.
```
