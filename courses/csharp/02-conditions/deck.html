### შედარება აბრუნებს bool-ს ```csharp Program.cs int age = 16; string name = "ნიკა"; bool isAdult = age >= 18; bool isSixteen = age == 16; bool isNotAna = name != "ანა"; Console.WriteLine(isAdult); // False Console.WriteLine(isSixteen); // True Console.WriteLine(isNotAna); // True ``` `age >= 18` — ეს **კითხვაა**, და მისი პასუხი (`true` ან `false`) `bool` ცვლადში ჩაიდება. | ოპერატორი | კითხვა | |---|---| | `==` | ტოლია? | | `!=` | არ უდრის? | | `>` `<` | მეტია? ნაკლებია? | | `>=` `<=` | მეტია ან ტოლი? ნაკლები ან ტოლი? | ```warn `=` — „ჩადე“ (მინიჭება). `==` — „ტოლია?“ (შედარება). ორი სულ სხვა რამ! ```

&& · || · ! — და, ან, არა

### და, ან, არა: `&&` · `||` · `!` ```csharp ✈️ ფრენა bool hasTicket = true; bool hasPassport = false; bool isVip = true; bool canFly = hasTicket && hasPassport; // False bool fastLane = isVip || hasTicket; // True bool noTicket = !hasTicket; // False ``` - `&&` — **და**: true, როცა **ორივე** true-ა. - `||` — **ან**: true, როცა **ერთი მაინც** true-ა. - `!` — **არა**: აბრუნებს — true ↔ false.
