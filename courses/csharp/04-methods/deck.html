## ნაწილი 1 · პირველი მეთოდი სახელი, პარამეტრები და დასაბრუნებელი მნიშვნელობა — JS-ის `function`-ის ძმა.
გამოცხადება და გამოძახება

function → void

JavaScript function printLine() { console.log("=========="); } printLine(); printLine();
C# PrintLine(); PrintLine(); void PrintLine() { Console.WriteLine("=========="); }
void — „არაფერს აბრუნებს“, უბრალოდ აკეთებს
სახელი დიდი ასოთი: PrintLine — როგორც WriteLine
Program.cs-ში მეთოდებს ბოლოში ვწერთ, ძირითადი კოდი — ზემოთ
### გამოცხადება და გამოძახება ```javascript JavaScript function printLine() { console.log("=========="); } printLine(); printLine(); ``` ```csharp C# PrintLine(); PrintLine(); void PrintLine() { Console.WriteLine("=========="); } ``` - `function`-ის ადგილას — **`void`**: „ეს მეთოდი არაფერს აბრუნებს, უბრალოდ აკეთებს“. - სახელი **დიდი ასოთი** (PascalCase): `PrintLine`, როგორც `WriteLine`. - Program.cs-ში მეთოდებს **ბოლოში** ვწერთ, ძირითად კოდს — ზემოთ. გამოძახება ზემოდანაც მუშაობს. ```terms გამოცხადება — მეთოდის დაწერა: რა ჰქვია და რას აკეთებს გამოძახება — მეთოდის გაშვება სახელით: PrintLine(); ```
