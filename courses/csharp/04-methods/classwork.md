# დავალებები — აირჩიე დონე

ყოველი მეთოდი გამოიძახე და შედეგი დაბეჭდე

## ნაბიჯები

- ⭐ **პატარა მეთოდები** — `int Square(int n)`, `bool IsEven(int n)`, `bool IsAdult(int age)`
- ⭐⭐ **ტემპერატურა** — `double CelsiusToFahrenheit(double c)` და `string DescribeWeather(double c)`: 0-ზე ნაკლები → „ყინავს ❄️“, 25-ზე მეტი → „ცხელა ☀️“, სხვა → „სასიამოვნოა 🌤️“
- ⭐⭐ **მასივის მეთოდები** — `int Min(int[] numbers)`, `int Sum(int[] numbers)`, `int CountAbove(int[] numbers, int limit)`. სცადე ორ სხვადასხვა მასივზე

## ✓ მზადაა, როცა

ძირითად კოდში მხოლოდ გამოძახებებია, ყველა გამოთვლა — მეთოდებში; მასივზე `{ 9, 7, 10, 6 }` და `limit = 8`-ზე `CountAbove` აბრუნებს `2`-ს

## ⭐ ბონუსი

- ⭐⭐⭐ `bool IsPrime(int n)` — მარტივია თუ არა რიცხვი. მისი დახმარებით დაბეჭდე ყველა მარტივი 1-დან 100-მდე
- 🏆 `void PrintBox(string text)` — ტექსტს ჩარჩოში სვამს, ჩარჩოს სიგანე ტექსტის სიგრძეზეა დამოკიდებული (`text.Length`)

## 💡 მინიშნება

`DescribeWeather` სტრიქონს აბრუნებს — switch expression-ითაც შეიძლება: `c switch { < 0 => "…", > 25 => "…", _ => "…" }`. `IsPrime`-ში: 2-დან `n - 1`-მდე თუ რომელიმეზე იყოფა (`n % i == 0`) → `return false;` — `return` მეთოდს მაშინვე ამთავრებს, ციკლსაც.
