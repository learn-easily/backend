# დავალებები — აირჩიე დონე

ახალი პერსონაჟები Arena პროექტში — ყველა `Character`-ის შვილი

## ნაბიჯები

- ⭐ **მშვილდოსანი** — `Archer : Character` (90 სიცოცხლე): `Arrows { get; private set; }` = 10 და `int Shoot()` — ისარი არ არის → 0; თუ არის → ერთი იხარჯება და `RollDamage(10, 18)`
- ⭐⭐ **მონსტრები** — `Goblin` (40 სიცოცხლე, `Stab()` 3–8) და `Orc` (80, `Club()` 8–15): ორივე `Character`-ის შვილი, **პარამეტრების გარეშე** კონსტრუქტორით
- ⭐⭐ **ერთ მასივში** — `Character[] all = { archer, goblin, orc };` → `foreach`-ით დაბეჭდე ყველას სახელი და სიცოცხლე

## ✓ მზადაა, როცა

`new Goblin()` სახელს თვითონ იღებს; 11-ე `Shoot()` 0-ს აბრუნებს; `archer.Arrows = 50` და `orc.RollDamage(1, 2)` Main-ში წითელ ხაზს აჩენს

## ⭐ ბონუსი

- ⭐⭐⭐ **მშვილდოსანი vs ორკი** — ბრძოლა `Shoot()`-ით და `Club()`-ით. ისრები გაუთავდა? მშვილდოსანი მშობლის `Attack()`-ს იყენებს

## 💡 მინიშნება

`public Goblin() : base("გობლინი", 40) { }` — სახელს და სიცოცხლეს შვილი თვითონ აწვდის მშობელს. `Shoot()`-ში: `if (Arrows == 0) return 0;`, მერე `Arrows--;`.
