# დავალებები — აირჩიე დონე

ახალი გმირი Arena-ს გუნდში — `Character`-ის შვილი. წინა საკლასოდან: `Gold`, `BuyPotion`, `Chest`

## ნაბიჯები

- ⭐ **ბერსერკი** — `Berserker : Character` (100 სიცოცხლე): `int Rage()` — ძლიერი დარტყმა `RollDamage(20, 30)`, მაგრამ რისხვა ძვირი ჯდება: ყოველ ჯერზე თავადაც კარგავს 5 სიცოცხლეს
- ⭐⭐ **ბერსერკი ბრძოლაში** — `Berserker berserker = new Berserker("ნიკა");` → ყოველ რაუნდში (თუ ცოცხალია) დრაკონს `Rage()`-ით ურტყამს. დრაკონის სამიზნე: ჯერ მეომარი, მერე ბერსერკი, მერე ჯადოქარი. `while`-ის პირობაც შეცვალე
- ⭐⭐ **ზარდახშა გუნდისთვის** — `Chest.Open(Hero hero)` → `Open(Character hero)`. ბრძოლის შემდეგ ზარდახშას პირველი ცოცხალი გმირი ხსნის

## ✓ მზადაა, როცა

ბერსერკს სახელსა და სიცოცხლეს მშობელი აძლევს; ყოველი `Rage()` მას 5-ით ასუსტებს; `berserker.RollDamage(1, 2)` Main-ში წითელ ხაზს აჩენს; შეგიძლია ახსნა, რატომ არ უნდა იყოს `Chest : Character` — ზარდახშა პერსონაჟი **არ არის**

## ⭐ ბონუსი

- ⭐⭐⭐ **მეორე ბერსერკი** — დაამატე კიდევ ერთი. დაითვალე, ბრძოლის კოდში რამდენ ადგილას მოგიწია ცვლილება. ეს პრობლემა შემდეგ ლექციაზე გაქრება

## 💡 მინიშნება

`public Berserker(string name) : base(name, 100) { }`. `Rage()`-ში: `TakeDamage(5); return RollDamage(20, 30);` — `TakeDamage` მშობლისგან მოდის, `RollDamage` კი `protected`-ია: შვილი ხედავს, Main — ვერა. სამიზნე — `if / else if / else` ჯაჭვი.
