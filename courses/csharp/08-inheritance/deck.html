### 💡 მემკვიდრეობა: მეომარი არის პერსონაჟი **მემკვიდრეობა** — ახალი კლასი არსებულზე შენდება: მშობლის ყველაფერი უკვე აქვს და თავისას ამატებს. - `Character` — **მშობელი** (base class): ყველაფერი საერთო, ერთხელ დაწერილი. - `Warrior`, `Mage`, `Dragon` — **შვილები** (derived class): მშობლის ყველაფერი + საკუთარი. შემოწმება — „X **არის** Y?“: მეომარი არის პერსონაჟი ✓, დრაკონი არის პერსონაჟი ✓, ხმალი არის პერსონაჟი ✗ — ხმალი მემკვიდრე არ იქნება. ```terms მემკვიდრეობა (inheritance) — კლასი სხვა კლასის ყველაფერს იღებს და თავისას ამატებს base class — მშობელი კლასი (Character) derived class — შვილი კლასი (Warrior) ```

## ნაწილი 2 · ვინ რას ხედავს? `private`, `public` — და ახალი: `protected`.
💥 პრობლემა კოდში

შვილიც კი ვერ ხედავს private-ს

public void FullRestore() // Mage.cs-ში { Health = MaxHealth; // ❌ CS0272 }
Health-ის set — private Character-ში. Mage სხვა კლასია

და ეს კარგია: შვილიც კი მშობლის წესებს გვერდს ვერ აუვლის — სიცოცხლე მაინც MaxHealth-ზე ჩერდება
### 💥 პრობლემა კოდში: შვილიც კი ვერ ხედავს private-ს ```csharp Mage.cs public void FullRestore() // Mage.cs-ში { Health = MaxHealth; // ❌ CS0272 } ``` `Health`-ის `set` private-ია **Character-ში**. Mage სხვა კლასია — ამიტომ მასაც ეკრძალება. სწორი გზა — მშობლის public მეთოდი: ```csharp Mage.cs public void FullRestore() // Mage.cs-ში { Heal(MaxHealth); // ✓ public მეთოდი } ``` და ეს კარგია: შვილიც კი მშობლის წესებს გვერდს ვერ აუვლის.

### ⌨️ protected — მხოლოდ ოჯახისთვის ყველა შვილში `Random.Shared.Next(15, 26)` მეორდება, და ყოველ ჯერზე უნდა გახსოვდეს, რომ ზედა ზღვარი არ შედის („+1“). დამხმარე მეთოდი გვინდა — მაგრამ არა გარედან ხელმისაწვდომი. ```csharp Character.cs + Warrior.cs // Character.cs protected int RollDamage(int min, int max) { return Random.Shared.Next(min, max + 1); } public int Attack() { return RollDamage(5, 15); } // Warrior.cs public int Smash() { return RollDamage(15, 25); } ``` - `protected` — ჩანს კლასში **და მის შვილებში**. გარედან — არა. - `Smash()` Warrior-ში — ✓. `luka.RollDamage(1, 5)` Program.cs-ში — ❌ CS0122. - „+1“ ახლა ერთ ადგილასაა. Mage-ის `Fireball`-იც ასე ხდება: `return RollDamage(25, 35);`.
