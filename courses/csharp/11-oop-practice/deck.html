### 💡 გავიხსენოთ: OOP — ოთხი პრინციპი 1. 🛡️ **ინკაფსულაცია** — `private` ველი, `{ get; private set; }`, property წესით; მონაცემი იცვლება მხოლოდ მეთოდებით. 2. 🧬 **მემკვიდრეობა** — `class B : A`, `: base(...)`, `protected`; მხოლოდ ერთი მშობელი. 3. 🎭 **პოლიმორფიზმი** — `virtual` / `override`, `base.Method()`, `override ToString()`; მშობლის ტიპის მასივი და ერთი ციკლი. 4. 🎨 **აბსტრაქცია** — `abstract` კლასი და მეთოდი; `interface` — „შეუძლია“, ბევრი ერთ კლასს.
💡 ახსნა · როგორ ვფიქრობთ

OOP პროექტი — ხუთი კითხვით იწყება

1 · ვინ / რა?არსებითი სახელები → კლასები
2 · ვინ „არის“?ბარათით გადახდა არის გადახდა → მემკვიდრეობა
3 · რა „შეუძლია“?ზოგს შეუძლია თანხის დაბრუნება → ინტერფეისი
4 · რა დავიცვათ?თანხა უარყოფითი არ არის, ბარათის ნომერი დამალულია → private + წესები
5 · რა განსხვავდება?თითოეული თავისებურად იხდის → abstract / override
### 💡 როგორ ვფიქრობთ: OOP პროექტი ხუთი კითხვით იწყება 1. **ვინ / რა?** — დავალების არსებითი სახელები → კლასები. 2. **ვინ „არის“ ვინ?** — „ბარათით გადახდა არის გადახდა“ → მემკვიდრეობა. 3. **რა „შეუძლია“ ზოგს?** — „ზოგს შეუძლია თანხის დაბრუნება“ → ინტერფეისი. 4. **რა უნდა დავიცვათ?** — „თანხა უარყოფითი არ არის“, „ბარათის ნომერი დამალულია“ → `private` და წესები. 5. **რა განსხვავდება?** — „თითოეული თავისებურად იხდის“ → `abstract` მეთოდი და `override`. კოდს მხოლოდ ამის შემდეგ ვწერთ.

### 🧩 დავალება: ონლაინ მაღაზიის სალარო **მოთხოვნები:** - მომხმარებელი იხდის ბარათით, ნაღდით ან ციფრული საფულით. - თანხა უარყოფითი ვერ იქნება. - ბარათის ნომრიდან ჩანს მხოლოდ ბოლო 4 ციფრი. - საფულეში ფული თუ არ ჰყოფნის — გადახდა არ ხერხდება. - ბარათით და საფულით გადახდილი თანხა ბრუნდება, ნაღდი — არა. - სალარო ყველა გადახდას ერთი ციკლით ამუშავებს. **ხუთი კითხვა:** 1. კლასები: `Payment`, `CardPayment`, `CashPayment`, `WalletPayment`. 2. ბარათით გადახდა **არის** გადახდა → `abstract class Payment`. 3. თანხის დაბრუნება **შეუძლია** ზოგს → `interface IRefundable`. 4. დავიცვათ: თანხა, ბარათის ნომერი, ბალანსი → `private`. 5. თითოეული თავისებურად იხდის → `abstract bool Pay()`.
⌨️ ერთად ვწერთ · Payment.cs · IRefundable.cs

მშობელი და ხელშეკრულება

internal abstract class Payment { public decimal Amount { get; private set; } public Payment(decimal amount) { if (amount < 0) amount = 0; Amount = amount; } public abstract bool Pay(); public override string ToString() { return $"{Amount} ₾"; } } internal interface IRefundable { void Refund(); }
ახალი პროექტი: Console App → Checkout
🛡️ decimal — ფულისთვის: ზუსტია. private set + წესი კონსტრუქტორში
🎨 abstract Pay() — „ყველა იხდის, როგორ — შვილი იტყვის“. bool: მოხერხდა?
🎨 IRefundable — „შეუძლია დაბრუნება“
### ⌨️ Payment.cs + IRefundable.cs: მშობელი და ხელშეკრულება ახალი პროექტი: **Console App → Checkout**. ```csharp Payment.cs + IRefundable.cs internal abstract class Payment { public decimal Amount { get; private set; } public Payment(decimal amount) { if (amount < 0) amount = 0; Amount = amount; } public abstract bool Pay(); public override string ToString() { return $"{Amount} ₾"; } } internal interface IRefundable { void Refund(); } ``` - 🛡️ `decimal` — ფულისთვის განკუთვნილი ტიპი: `double`-სგან განსხვავებით, თეთრებს არ „კარგავს“. `Amount` — `private set` და წესი კონსტრუქტორში. - 🎨 `abstract bool Pay()` — „ყველა იხდის, როგორ — შვილი იტყვის“. `bool` — მოხერხდა თუ არა. - 🎨 `IRefundable` — „შეუძლია თანხის დაბრუნება“.

internal class CardPayment : Payment, IRefundable { private string cardNumber; public CardPayment(decimal amount, string number) : base(amount) { cardNumber = number; } public string Masked() { return "**** " + cardNumber.Substring(cardNumber.Length - 4); } public override bool Pay() { Console.WriteLine($"💳 ბარათი {Masked()} → {Amount} ₾"); return true; } public void Refund() { Console.WriteLine($"↩️ {Amount} ₾ დაბრუნდა ბარათზე {Masked()}"); } }
🛡️ ნომერი — private ველი, property-იც კი არა. გარედან ვერავინ წაიკითხავს
Substring — string-ის მეთოდი: ტექსტი მითითებული ადგილიდან ბოლომდე. ბოლო 4 ციფრი

### ⌨️ CardPayment.cs — ნომერი დამალულია ```csharp CardPayment.cs · namespace-ის შიგნით internal class CardPayment : Payment, IRefundable { private string cardNumber; public CardPayment(decimal amount, string number) : base(amount) { cardNumber = number; } public string Masked() { return "**** " + cardNumber.Substring(cardNumber.Length - 4); } public override bool Pay() { Console.WriteLine($"💳 ბარათი {Masked()} → {Amount} ₾"); return true; } public void Refund() { Console.WriteLine($"↩️ {Amount} ₾ დაბრუნდა ბარათზე {Masked()}"); } } ``` - 🛡️ ბარათის ნომერი — `private` ველი, property-იც კი არა. გარედან ვერავინ წაიკითხავს. - `Substring(start)` — string-ის მეთოდი: ტექსტი `start` პოზიციიდან ბოლომდე. `Length - 4` → ბოლო ოთხი ციფრი. ყველაფერი ობიექტია! - 🎭 `override Pay()` — თავისებურად; 🎨 `Refund()` — ხელშეკრულება შესრულდა.

internal class WalletPayment : Payment, IRefundable { public decimal Balance { get; private set; } public WalletPayment(decimal amount, decimal balance) : base(amount) { Balance = balance; } public override bool Pay() { if (Balance < Amount) { Console.WriteLine($"❌ საფულეში მხოლოდ {Balance} ₾ — არ ჰყოფნის"); return false; } Balance -= Amount; Console.WriteLine($"📱 საფულე → {Amount} ₾ (დარჩა {Balance} ₾)"); return true; } public void Refund() { Balance += Amount; Console.WriteLine($"↩️ {Amount} ₾ დაბრუნდა საფულეში ({Balance} ₾)"); } }
🛡️ ბალანსი — ჩანს, მაგრამ იცვლება მხოლოდ Pay-ით და Refund-ით
