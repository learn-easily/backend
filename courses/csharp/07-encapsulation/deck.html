## ნაწილი 1 · public და private ვინ ხედავს კლასის წევრს?
⌨️ ერთად ვწერთ · ზარდახშა

private ველი — public მეთოდები

internal class Chest { private int gold = 100; public int GetGold() { return gold; } public void AddGold(int amount) { if (amount > 0) gold += amount; } }
ველი (field) — ცვლადი კლასში, { get; set; }-ის გარეშე. private → მხოლოდ კლასის შიგნით ჩანს
public მეთოდები — კარი: წაკითხვა და დამატება, წესით
Chest chest = new Chest(); chest.gold = 99999; // ❌ CS0122 chest.AddGold(-500); // ✓ წესი: არაფერი შეიცვლება chest.AddGold(50); // ✓ 150 Console.WriteLine(chest.GetGold());
chest.gold — წითელი ხაზი: „inaccessible due to its protection level“
### ⌨️ ზარდახშა: private ველი — public მეთოდები ```csharp Chest.cs · namespace-ის შიგნით internal class Chest { private int gold = 100; public int GetGold() { return gold; } public void AddGold(int amount) { if (amount > 0) gold += amount; } } ``` ```csharp Program.cs · Main Chest chest = new Chest(); chest.gold = 99999; // ❌ CS0122 chest.AddGold(-500); // ✓ წესი: არაფერი შეიცვლება chest.AddGold(50); // ✓ 150 Console.WriteLine(chest.GetGold()); ``` - **ველი** (field) — ცვლადი კლასის შიგნით, `{ get; set; }`-ის გარეშე. ველს პატარა ასოთი ვარქმევთ: `gold`. - `private` — ჩანს **მხოლოდ კლასის შიგნით**. `chest.gold` გარედან — შეცდომა CS0122: *inaccessible due to its protection level*. - `public` მეთოდები — „კარი“: ოქროს წაკითხვა და დამატება შეიძლება, მაგრამ მხოლოდ წესით — უარყოფით თანხას `AddGold` არ იღებს.
