# დავალებები — აირჩიე დონე

ახალი კლასები Arena პროექტში — ყველა მონაცემი დაცულია

## ნაბიჯები

- ⭐ **საფულე** — `Wallet`: `Gold { get; private set; }`, `void Earn(int amount)` (მხოლოდ დადებითი), `bool Spend(int amount)` — ოქრო არ ჰყოფნის → `false` და არაფერი იცვლება
- ⭐⭐ **ხმალი** — `Weapon`: `Name` (property წესით: ცარიელი → „ჟანგიანი ხმალი“), `Durability { get; private set; }` = 100, `int Use()` — აბრუნებს დაზიანებას (15) და გამძლეობას 10-ით ამცირებს; გამძლეობა 0 → დაზიანება 1. `void Repair()` → 100
- ⭐⭐ **გმირის ოქრო** — `Hero`-ს დაუმატე `Gold { get; private set; }`, `AddGold(int amount)` და `bool BuyPotion()` — 25 ოქრო → +1 წამალი

## ✓ მზადაა, როცა

`wallet.Gold = 999` და `sword.Durability = 100` წითელ ხაზს აჩენს; `Spend` და `BuyPotion` ოქროს არ აკლებს, როცა არ ჰყოფნის; გატეხილი ხმალი 1-ს ურტყამს

## ⭐ ბონუსი

- ⭐⭐⭐ **ჯილდო** — არენაში დრაკონის მოკვლის შემდეგ რაინდი 50 ოქროს იღებს და რამდენ წამალსაც ყიდულობს, იმდენი იყიდოს — ციკლით: `while (knight.BuyPotion())`

## 💡 მინიშნება

`Spend`: ჯერ შეამოწმე — `if (amount > Gold) return false;`, მერე შეცვალე. `BuyPotion`-ის შიგნით `Potions++` შეიძლება — კლასის შიგნით ხარ. `while (knight.BuyPotion()) { }` — ციკლი თავისით ჩერდება, როცა `false` დაბრუნდება.
