# დავალებები — აირჩიე დონე

ოქრო, წამლების ყიდვა და ზარდახშა Arena-ში — ყველაფერი დაცულია

## ნაბიჯები

- ⭐ **გმირის ოქრო** — `Hero`-ს დაუმატე `Gold { get; private set; } = 50` და `void AddGold(int amount)` — მხოლოდ დადებითი რიცხვი
- ⭐⭐ **წამლის ყიდვა** — `bool BuyPotion()`: 25 ოქრო → +1 წამალი; ოქრო არ ჰყოფნის → `false` და არაფერი იცვლება. ბრძოლამდე რაინდი ყიდულობს, რამდენიც ეყოფა: `while (knight.BuyPotion()) { }` — ბრძოლაში მათ უკვე არსებული `UsePotion` ხაზი იყენებს
- ⭐⭐ **ზარდახშა თამაშში** — ლექციის `Chest` გადააკეთე: კონსტრუქტორი `Chest(int gold)` (უარყოფითი → 0), `IsOpen { get; private set; }` და `void Open(Hero hero)` — ოქროს გმირს აძლევს `AddGold`-ით. უკვე გახსნილი ან მკვდარი გმირი → არაფერი ხდება. ბრძოლის შემდეგ: `if (knight.IsAlive()) chest.Open(knight);` და დაბეჭდე `knight.Gold`

## ✓ მზადაა, როცა

`knight.Gold = 999` და `chest.gold = 999` წითელ ხაზს აჩენს; ბრძოლამდე რაინდს 5 წამალი აქვს (3 + 2 ნაყიდი); ზარდახშას მეორედ ვერ გაძარცვავ; ოქრო მინუსში არასდროს ჩადის

## ⭐ ბონუსი

- ⭐⭐⭐ **ხაფანგიანი ზარდახშა** — `IsTrapped { get; private set; }` — კონსტრუქტორში 20%-ით `true`. `Open`-ში: თუ ხაფანგიანია → ჯერ `hero.TakeDamage(20)` და „🪤“, მერე ოქრო

## 💡 მინიშნება

`BuyPotion`: ჯერ შემოწმება — `if (Gold < 25) return false;`, მერე `Gold -= 25; Potions++;` — კლასის შიგნით ხარ, `private set` აქ არ გიშლის. `Open`: `if (IsOpen || !hero.IsAlive()) return;`. 20% — `Random.Shared.Next(100) < 20`.
