# დავალებები — აირჩიე დონე

დაიწყე ⭐-დან და ზევით აიწიე

## ნაბიჯები

- ⭐ **მისალმება** — ჰკითხე სახელი და ასაკი. 18+ → „გამარჯობა, ზრდასრულო {name}!“, სხვა შემთხვევაში → „გამარჯობა, მოსწავლე {name}!“
- ⭐⭐ **კალკულატორი** — ორი რიცხვი და ოპერაცია: `+ - * /`. 0-ზე გაყოფა → წითელი შეცდომის ტექსტი
- ⭐⭐ **გამრავლების ტაბულა** — შეიყვანე რიცხვი → `7 x 1 = 7` … `7 x 10 = 70`

## ✓ მზადაა, როცა

პროგრამა ეშვება (Ctrl+F5) და სხვადასხვა რიცხვზე სწორ პასუხს ბეჭდავს

## ⭐ ბონუსი

- ⭐⭐⭐ **ბიპ-ბუპ** — 1-დან 50-მდე: 3-ზე იყოფა → ბიპ, 5-ზე → ბუპ, ორივეზე → ბიპბუპ, სხვა → რიცხვი
- 🏆 „გამოიცანი რიცხვი“ — მაქსიმუმ 7 ცდა, მერე „Game Over“ და სწორი პასუხი

## 💡 მინიშნება

კალკულატორში ოპერაცია ტექსტია: `string op = Console.ReadLine();` და მერე `if (op == "+")` ან `switch (op)`. 0-ზე გაყოფა **გაყოფამდე** შეამოწმე. ტაბულისთვის — `for (int i = 1; i <= 10; i++)`.
