კომპილატორი კოდს გაშვებამდე ამოწმებს. შეცდომაა? პროგრამა არ გაეშვება — სანამ არ გაასწორებ.

### კოდიდან შედეგამდე: JS ბრაუზერში vs C# კომპიუტერზე - **JavaScript**: `app.js` → ბრაუზერი კითხულობს და მაშინვე უშვებს → შედეგი. შეცდომას მხოლოდ მაშინ გაიგებ, როცა ის ხაზი შესრულდება. - **C#**: `Program.cs` → 🔍 **კომპილატორი** (Build) → `FirstApp.dll` → .NET → შედეგი. **კომპილატორი კოდს გაშვებამდე ამოწმებს.** შეცდომაა? პროგრამა არ გაეშვება — სანამ არ გაასწორებ. ```terms კომპილატორი — პროგრამა, რომელიც შენს კოდს ამოწმებს და კომპიუტერისთვის გასაგებ ფაილად თარგმნის ```
