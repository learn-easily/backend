# დავალებები — აირჩიე დონე

Arena-ს სრული თამაში: მაღაზია → ბრძოლა → ნადავლი. წინა საკლასოებიდან: `Gold`, `BuyPotion`, `Chest`, `Berserker`

## ნაბიჯები

- ⭐ **პალადინი** — `Paladin : Character, IHealer` (110): მეომარიც და მკურნალიც — `Attack()` 10–18, `HealAlly` → +10. დაამატე `party`-შიც და `healers`-შიც
- ⭐⭐ **ზარდახშა — ნადავლი** — `Chest : ILootable`: `DropGold()` ოქროს ერთხელ აბრუნებს, მეორედ — 0 (`Open`-ის ლოგიკა აქ გადადის). გამარჯვების შემდეგ `ILootable[] loot = { dragon, chest };` → შეკრიბე ოქრო და თანაბრად გაუნაწილე ცოცხალ გმირებს `AddGold`-ით
- ⭐⭐ **მაღაზია** — ბრძოლამდე ყოველი გმირი ყიდულობს წამლებს: `foreach` + `while (hero.BuyPotion()) { }`. ბრძოლაში გმირის სვლისას: `if (hero.Health < 30) hero.UsePotion();`

## ✓ მზადაა, როცა

პალადინი ორივე მასივში ეტევა; ნადავლი ერთი ციკლით გროვდება და ცოცხალ გმირებზე ნაწილდება; ნაყიდი წამლები ბრძოლაში იხარჯება; შეგიძლია ახსნა, რატომ ვერ ექნებოდათ `Dragon`-სა და `Chest`-ს საერთო მშობელი — და რატომ ეტევიან მაინც ერთ მასივში

## ⭐ ბონუსი

- ⭐⭐⭐ **სამი სართული** — მაღაზია → ბრძოლა → ნადავლი ჩასვი `for (int floor = 1; floor <= 3; floor++)`-ში. ყოველ სართულზე — ახალი დრაკონი (`Dragon(int floor)` → 200 + floor × 50 სიცოცხლე) და ახალი ზარდახშა; გუნდი, ოქრო და წამლები შემდეგ სართულზე გადადის. გუნდი დაიღუპა → `break`

## 💡 მინიშნება

`class Chest : ILootable` — მშობელი არ ჰყავს, მხოლოდ ინტერფეისი. გაყოფა: ჯერ დაითვალე ცოცხლები (`int alive`), მერე `total / alive` თითოეულს. `Dragon(int floor) : base("დრაკონი", 200 + floor * 50)`.
