# დავალებები — აირჩიე დონე

Arena პროექტში — abstract და ინტერფეისები

## ნაბიჯები

- ⭐ **ოქროიანი გობლინი** — `Goblin : Character, ILootable` (40 სიცოცხლე, პარამეტრების გარეშე): `Attack()` 3–8 და `DropGold()` 5–15
- ⭐⭐ **პალადინი** — `Paladin : Character, IHealer` (110): მეომარიც და მკურნალიც — `Attack()` 10–18, `HealAlly` → +10. დაამატე `party`-შიც და `healers`-შიც
- ⭐⭐ **ნადავლი** — `ILootable[] loot = { goblin, dragon };` → ციკლით შეკრიბე და დაბეჭდე ჯამური ოქრო

## ✓ მზადაა, როცა

`Goblin`-ს `Attack()` რომ წაუშალო — წითელი ხაზი; პალადინი ორივე მასივში ეტევა; ჯამური ოქრო იბეჭდება

## ⭐ ბონუსი

- ⭐⭐⭐ **ახალი ინტერფეისი** — `IHasShield` (`int Block()` — რამდენს ბლოკავს). მეომარი და პალადინი ახორციელებენ. ბრძოლის ბოლოს დაბეჭდე, ვის აქვს ფარი — `IHasShield[]`-ით

## 💡 მინიშნება

`class Goblin : Character, ILootable` — ჯერ მშობელი, მერე ინტერფეისი. ინტერფეისის მეთოდი კლასში `public` უნდა იყოს. ჯამური ოქრო: `int total = 0; foreach (ILootable l in loot) total += l.DropGold();`.
