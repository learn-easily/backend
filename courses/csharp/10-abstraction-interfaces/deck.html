## ნაწილი 1 · abstract კლასი იდეა, რომლის შექმნაც შეუძლებელია.
⌨️ ერთად ვწერთ · Character.cs

ერთი სიტყვა — abstract

internal abstract class Character { // … ყველაფერი, როგორც იყო }
abstract — „ეს მხოლოდ ნახაზის ნახაზია: ობიექტს ვერ შექმნი“
Character who = new Character("???", 100); // ❌ CS0144 Character c = new Warrior("ლუკა"); // ✓ Character[] party = { c, new Mage("ანა") }; // ✓
new Character → „Cannot create an instance of the abstract type“
ცვლადის ტიპად და მასივში — კი. პოლიმორფიზმი რჩება
### ⌨️ ერთი სიტყვა — abstract ```csharp Character.cs internal abstract class Character { // … ყველაფერი, როგორც იყო } ``` ```csharp Program.cs · Main Character who = new Character("???", 100); // ❌ CS0144 Character c = new Warrior("ლუკა"); // ✓ Character[] party = { c, new Mage("ანა") }; // ✓ ``` - `abstract class` — „ეს მხოლოდ იდეაა: ობიექტს ვერ შექმნი“. `new Character(...)` → შეცდომა CS0144: *Cannot create an instance of the abstract type*. - ცვლადის ტიპად და მასივში `Character` ისევ გამოიყენება — პოლიმორფიზმი რჩება. - შვილები (`Warrior`, `Mage`…) — ჩვეულებრივი კლასებია, მათი შექმნა შეიძლება. ```terms abstract class — კლასი, რომლის ობიექტიც ვერ შეიქმნება; მხოლოდ მშობლად გამოიყენება ```
⌨️ ერთად ვწერთ · Character.cs · Mage.cs

abstract მეთოდი — „ყველამ უნდა დაწეროს“

// Character.cs — ტანი აღარ აქვს public abstract int Attack(); // Mage.cs — base.Attack() აღარ არსებობს public override int Attack() { if (Mana < 20) return RollDamage(3, 8); // 🪄 ჯოხით Mana -= 20; return RollDamage(25, 35); }
ტანი არ აქვს — მხოლოდ ;. „ყველა პერსონაჟი უტევს — როგორ, შვილი იტყვის“
ქურდი Attack()-ის გარეშე → CS0534: „does not implement inherited abstract member“
base.Attack() აღარ შეიძლება (CS0205) — მშობელს ტანი არ აქვს. ჯადოქარს — საკუთარი ჯოხის დარტყმა
დავიწყება შეუძლებელია — კომპილატორი თვითონ შეგახსენებს
### ⌨️ abstract მეთოდი — „ყველამ უნდა დაწეროს“ ```csharp Character.cs + Mage.cs // Character.cs — ტანი აღარ აქვს public abstract int Attack(); // Mage.cs — base.Attack() აღარ არსებობს public override int Attack() { if (Mana < 20) return RollDamage(3, 8); // 🪄 ჯოხით Mana -= 20; return RollDamage(25, 35); } ``` - `abstract` მეთოდს ტანი არ აქვს — მხოლოდ `;`. „ყველა პერსონაჟი უტევს — როგორ, შვილი იტყვის“. - შვილი **ვალდებულია** დაწეროს `override`. ქურდი `Attack()`-ის გარეშე → შეცდომა CS0534: *does not implement inherited abstract member*. - `base.Attack()` აღარ შეიძლება (CS0205) — მშობელს ტანი აღარ აქვს. ჯადოქარს მანის გარეშე საკუთარი, ჯოხის დარტყმა აქვს: 3–8. - `abstract` მეთოდი მხოლოდ `abstract` კლასში შეიძლება.
