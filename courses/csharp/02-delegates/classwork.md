# თამაშის გაფართოება — აირჩიე დონე

დაიწყე ⭐-დან და ზევით აიწიე. ყველა დავალება დღევანდელ თამაშს აფართოებს.

## ნაბიჯები

- ⭐ **ახალი რეაქციები** — 35+ დაზიანებაზე „⚡ კრიტიკული დარტყმა!“ და ბოტის განკურნებების მთვლელი. მხოლოდ ახალი `+=` ხაზები
- ⭐⭐ **ახალი მოვლენა** — `Action OnLowHealth`: ერთხელ, როცა HP პირველად ჩამოვა 25-ზე ქვემოთ → „⚠️ სიცოცხლე კრიტიკულია!“
- ⭐⭐⭐ **ბოტის სირთულე** — დასაწყისში `ადვილი / რთული?` → ორი სხვადასხვა ტვინი `bot.ChooseMove`-ში

## ✓ მზადაა, როცა

თამაში ბოლომდე თამაშდება და ახალი შეტყობინებები სწორ მომენტში ჩნდება

## ⭐ ბონუსი

- 🏆 ახალი სვლა **4 — ცეცხლის ბურთი**: 30-50 დაზიანება, მაგრამ მხოლოდ ერთხელ თამაშში

## 💡 მინიშნება

⭐ — ორივე ერთი ხაზია: `bot.OnDamaged += dmg => { if (dmg > 35) ... };` და `bot.OnHealed += hp => healCount++;`

⭐⭐ — `Fighter`-ს დასჭირდება `bool` ველი, რომელიც იმახსოვრებს, უკვე გამოიძახე თუ არა. შემოწმება `TakeDamage`-ის შიგნით ჩაწერე.

⭐⭐⭐ — **ადვილი:** ბოტი შემთხვევით ურტყამს და არასდროს იკურნება. **რთული:** იკურნება 40 HP-ზე ქვემოთ, ხოლო თუ შენ 30 HP-ზე ნაკლები გაქვს — ძლიერ დარტყმას ირჩევს. ორი სხვადასხვა ლამბდა დაწერე და `if`-ით აირჩიე, რომელი ჩაიწეროს `bot.ChooseMove`-ში. `Fighter` და `DoMove` არ იცვლება.
