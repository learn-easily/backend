ORM — თარჯიმანი C#-სა და ბაზას შორის. ჩვენ ვწერთ C#-ს, ის ბაზას ელაპარაკება SQL-ით.
### სამი ასო: O · R · M - **O — Object**: ობიექტი — C#-ის კლასები და ობიექტები. - **R — Relational**: რელაციური ბაზა — ცხრილები, სვეტები და მათი კავშირები (Foreign Key-ები). MS SQL სწორედ ასეთია. - **M — Mapping**: დაკავშირება — რა რას შეესაბამება ერთ და მეორე მხარეს. **ORM — თარჯიმანი C#-სა და ბაზას შორის.** ჩვენ ვწერთ C#-ს, ის ბაზას SQL-ით ელაპარაკება. ```terms ORM — Object-Relational Mapping: ბიბლიოთეკა, რომელიც C#-ის ობიექტებს ბაზის ცხრილებთან აკავშირებს და SQL-ს თვითონ წერს ```
Mapping

რა რას შეესაბამება

### Mapping: რა რას შეესაბამება | C# · კოდი | SQL · ბაზა | |---|---| | კლასი `class Product` | ცხრილი `Products` | | property `decimal Price` | სვეტი `Price` | | ობიექტი `new Product { … }` | ჩანაწერი (ერთი ხაზი) | ORM-მა ეს სამი წესი იცის, და მათით ორივე მიმართულებით თარგმნის.

როგორ თარგმნის ORM — ორივე მიმართულებით

### როგორ თარგმნის ORM — ორივე მიმართულებით „მომეცი 100 ლარზე იაფი პროდუქტები“: 1. **C# კოდი** — `db.Products.Where(p => p.Price < 100)`. SQL-ის არცერთი სიტყვა. 2. **ORM იღებს** — მან იცის ჩვენი Mapping. 3. **ORM თარგმნის** C# → SQL: `SELECT … FROM Products WHERE Price < 100`. ეს SQL ჩვენ არ დაგვიწერია! 4. **ბაზა** იღებს ჩვეულებრივ SQL-ს და აბრუნებს ჩანაწერებს. 5. **ORM თარგმნის უკან**: ჩანაწერები → `Product` ობიექტები.
