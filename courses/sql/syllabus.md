# SQL და PostgreSQL

**ტექნოლოგიები:** PostgreSQL 18 (Docker-ში), pgAdmin / DBeaver, SQL

**პროექტი:** **Shop**-ის ბაზა — C#-ის კურსის ონლაინ მაღაზია, რომელიც აქამდე JSON ფაილებში ინახებოდა: პროდუქტები, კატეგორიები, მომხმარებლები, კალათა, შეკვეთები, შეფასებები. ლექტორი ბაზას კლასში აწყობს; სტუდენტი იმავეს სახლში **თავისი საფინალო პროექტის** ბაზაზე იმეორებს (C#-ის კურსზე არჩეული სფერო). EF Core-ის კურსში C#-ის Shop ამ ბაზას უერთდება.

## საფუძვლები (2 ლექცია)

### 01. რატომ ბაზა — PostgreSQL და პირველი ცხრილი

**პრობლემა:** Shop-ის JSON ფაილებში ძებნა ნელია, ორი ერთდროული ცვლილება ერთმანეთს შლის, შეკვეთა და პროდუქტი არ არის დაკავშირებული. **თემები:** რა არის ბაზა და DBMS; რელაციური მოდელი — ცხრილი, სტრიქონი, სვეტი; SQL და მისი ნაწილები (DDL, DML); PostgreSQL vs სხვა ბაზები; Docker მოკლედ — რატომ და როგორ ვუშვებთ PostgreSQL-ს კონტეინერში; pgAdmin / DBeaver; ტიპები (`integer`, `bigint`, `numeric`, `text`, `varchar`, `boolean`, `date`, `timestamptz`, `uuid`); `CREATE TABLE` — `PRIMARY KEY`, `NOT NULL`, `DEFAULT`, `UNIQUE`, `CHECK` სვეტთან ერთად; `ALTER TABLE`, `DROP TABLE`.

📚 აუხსნის, რატომ არ კმარა ფაილი და რას გვაძლევს ბაზა
📚 გაუშვებს PostgreSQL-ს Docker-ში და დაუკავშირდება კლიენტით
📚 შექმნის ცხრილს სწორი ტიპებით და შეზღუდვებით
🛠 Shop | ბაზა `shop` · ცხრილები `categories`, `products`

### 02. CRUD — SELECT, INSERT, UPDATE, DELETE

**თემები:** `INSERT` (რამდენიმე სტრიქონი ერთად, `RETURNING`); `SELECT` — `WHERE`, `ORDER BY`, `LIMIT` / `OFFSET`; `IN`, `BETWEEN`, `LIKE` / `ILIKE`, `IS NULL`; `UPDATE` და `DELETE` — და რატომ არის საშიში `WHERE`-ის გარეშე.

📚 ჩაწერს, წაიკითხავს, შეცვლის და წაშლის მონაცემს
📚 გაფილტრავს და დაალაგებს შედეგს
📚 დაწერს გვერდებად ჩვენებას `LIMIT` / `OFFSET`-ით
🛠 Shop | პროდუქტების შევსება · ძებნა სახელით და ფასით · ფასის ცვლილება · მარაგიდან ამოღება

## ცხრილების დაპროექტება (2 ლექცია)

### 03. რელაციები — Foreign Key

**პრობლემა:** კატეგორიის სახელი ყოველ პროდუქტში მეორდება, შეკვეთაში კი პროდუქტი ტექსტად წერია. **თემები:** `REFERENCES` (FK); 1–1, 1–N, N–N და შუალედური ცხრილი; `ON DELETE CASCADE` / `RESTRICT` / `SET NULL`; მონაცემის მთლიანობა; ER დიაგრამა.

📚 დააკავშირებს ცხრილებს foreign key-ით
📚 გაარჩევს 1–1, 1–N და N–N კავშირებს და ააწყობს თითოეულს
📚 აირჩევს წაშლის სწორ ქცევას
🛠 Shop | `users` (email, password_hash, role) — C#-ში `users.json`-ში ინახებოდა · `customers` (→ `users`), `orders`, `order_items` (N–N: შეკვეთა ↔ პროდუქტი), `carts`, `cart_items`

### 04. ნორმალიზაცია

**პრობლემა:** ერთი დიდი ცხრილი — განახლების, ჩასმის და წაშლის ანომალიები. **თემები:** ანომალიები; 1NF, 2NF, 3NF მაგალითებით; როდის ვარღვევთ ნორმალიზაციას შეგნებულად (შეკვეთაში ფასის „ფოტო“); Shop-ის სრული სქემის დაპროექტება ერთად; **enum → ცხრილი:** C#-ში `Category` enum იყო — კოდის შეცვლის გარეშე ახალს ვერ დაამატებ; როცა ადმინს კატეგორიის დამატება სჭირდება, ის ცხრილი ხდება (`categories`), სტატუსი (`OrderStatus`, `role`) კი მნიშვნელობად რჩება.

📚 იპოვის ანომალიებს ცუდად დაპროექტებულ ცხრილში
📚 დაშლის ცხრილს 3NF-მდე
📚 დააპროექტებს სრულ ბაზას ამოცანიდან
📚 გაარჩევს, როდის რჩება მნიშვნელობა enum-ად და როდის ხდება ცხრილი
🛠 Shop | სრული სქემა: `reviews`, `addresses`, `discounts` · `order_items.unit_price` — ფასი ყიდვის მომენტში

## მოთხოვნები (2 ლექცია)

### 05. JOIN და UNION

**თემები:** რატომ JOIN; `INNER`, `LEFT`, `RIGHT`, `FULL JOIN`; რამდენიმე ცხრილის შეერთება; alias-ები; self-join მოკლედ; `UNION` / `UNION ALL`.

📚 გააერთიანებს რამდენიმე ცხრილის მონაცემს ერთ შედეგში
📚 გაარჩევს `INNER` და `LEFT JOIN`-ს და იცის, რომელი როდის
🛠 Shop | შეკვეთა მომხმარებლით და პროდუქტებით · პროდუქტები, რომლებიც არავის უყიდია

### 06. აგრეგაცია და subquery

**თემები:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`; `GROUP BY` და `HAVING` (vs `WHERE`); subquery `WHERE`-ში და `FROM`-ში; `EXISTS`, `IN`; CTE (`WITH`) მოკლედ.

📚 დაითვლის ჯამებს და საშუალოებს ჯგუფების მიხედვით
📚 დაწერს subquery-ს და CTE-ს
🛠 Shop | შემოსავალი კატეგორიით · საშუალო შეფასება · მომხმარებლები 3+ შეკვეთით · ტოპ-5 პროდუქტი

## ბაზა Production-ში (1 ლექცია)

### 07. ინდექსები, ტრანზაქციები, View და მეტი

📚 დაამატებს ინდექსს და დაინახავს განსხვავებას
📚 შეასრულებს რამდენიმე ცვლილებას ერთ ტრანზაქციაში
📚 გამოიყენებს view-ს და window function-ს ანგარიშისთვის
🛠 Shop | ინდექსი `products(name)` · შეკვეთის განთავსება ტრანზაქციით (შეკვეთა + მარაგი) · `view` შეკვეთების ჯამებით · პროდუქტის რეიტინგი კატეგორიაში
