### ერთი და იგივე endpoint — ორი გზით ```csharp Minimal API · Program.cs app.MapGet("/api/products", () => { return new[] { "ლეპტოპი", "მაუსი" }; }); ``` ```csharp Controller · Controllers/ProductsController.cs [ApiController] [Route("api/products")] public class ProductsController : ControllerBase { [HttpGet] public IActionResult GetAll() { return Ok(new[] { "ლეპტოპი", "მაუსი" }); } } ``` | | Minimal API | Controller | |---|---|---| | მისამართი + მეთოდი | `MapGet("/api/products")` — ერთ ხაზში | `[Route]` + `[HttpGet]` | | რას ვაბრუნებთ | ფუნქცია (lambda) | კლასის მეთოდი + `Ok(...)` | Controller-ში მეტი კოდია — ვნახოთ, რატომ.

Controller-ი — ნაწილ-ნაწილ

[ApiController] [Route("api/[controller]")] public class ProductsController : ControllerBase { [HttpGet] public IActionResult GetAll() { return Ok(new[] { "ლეპტოპი", "მაუსი" }); } }
1[ApiController] — „ეს კლასი API-ს ემსახურება“. რთავს API-სთვის საჭირო ქცევას
2[Route] — მისამართი. [controller] = კლასის სახელი „Controller“-ის გარეშე:
ProductsController → api/products
3: ControllerBase — მზა მეთოდებს გვაძლევს: Ok(), NotFound(), NoContent()… სახელი აუცილებლად …Controller-ით მთავრდება
4[HttpGet] — რომელ HTTP მეთოდზე პასუხობს ეს მეთოდი
5Action — ჩვეულებრივი მეთოდი. IActionResult = „პასუხი სტატუს კოდით“
### Controller — ნაწილ-ნაწილ ```csharp Controllers/ProductsController.cs [ApiController] [Route("api/[controller]")] public class ProductsController : ControllerBase { [HttpGet] public IActionResult GetAll() { return Ok(new[] { "ლეპტოპი", "მაუსი" }); } } ``` 1. **`[ApiController]`** — ატრიბუტი: „ეს კლასი API-ს ემსახურება“. რთავს API-სთვის საჭირო ქცევას — მაგ. არასწორ მონაცემზე თვითონ აბრუნებს 400-ს. 2. **`[Route("api/[controller]")]`** — მისამართი. `[controller]` = კლასის სახელი „Controller“-ის გარეშე: `ProductsController` → `api/products`. 3. **`: ControllerBase`** — მზა მეთოდებს გვაძლევს: `Ok()`, `NotFound()`, `NoContent()`… 4. **`[HttpGet]`** — HTTP მეთოდი. 5. **`IActionResult`** — „HTTP პასუხი“: სტატუს კოდი + მონაცემი. ```terms ატრიბუტი — [კვადრატულ ფრჩხილებში] დაწერილი „ნიშანი“ კლასზე ან მეთოდზე, რომელსაც framework კითხულობს IActionResult — მეთოდის დასაბრუნებელი ტიპი: სტატუს კოდი + (არასავალდებულო) მონაცემი ```

### Controller-ებს Program.cs-ში ორი ხაზი სჭირდება ```csharp Program.cs var builder = WebApplication.CreateBuilder(args); builder.Services.AddControllers(); var app = builder.Build(); app.MapControllers(); app.Run(); ``` 1. **`AddControllers()`** — „ჩემს პროექტში Controller-ები იქნება“ (რეგისტრაცია). 2. **`MapControllers()`** — „იპოვე ყველა Controller და მათი მისამართები მიაბი“: ProductsController → `api/products`, CategoriesController → `api/categories`… დანარჩენი კოდი ცალკე ფაილებშია.

### REST რომ არ არსებობდეს… სამ დეველოპერს ერთი დავალება აქვს — პროდუქტების API: - 👩‍💻 **A** ყველაფერს POST-ით აკეთებს, მოქმედებას მისამართში წერს: `POST /getAllProducts`, `POST /addNewProduct`, `POST /removeProduct?id=5`. - 🧑‍💻 **B** ყველაფერს GET-ით, წაშლასაც კი: `GET /products_list`, `GET /product/create?name=…`, `GET /delete-product/5`. - 👨‍💻 **C**-ს ერთი მისამართი აქვს, და რა ქნას — JSON-ში წერს. სამივე მუშაობს — მაგრამ Frontend დეველოპერმა ყოველ API-ზე თავიდან უნდა ისწავლოს ყველაფერი.
