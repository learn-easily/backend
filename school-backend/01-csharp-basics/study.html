ტიპი იწერება წინ

სლაიდი 20

C#

let-ის ადგილას ტიპი იწერება: int — მთელი რიცხვი, string — ტექსტი.

ყუთზე წერია int — მასში მხოლოდ მთელი რიცხვი ჩაეტევა. (TypeScript-ში ტიპს ბოლოში წერდი: let age: number. C#-ში — წინ.)

ძირითადი ტიპები

სლაიდი 21

JS-ში ყველა რიცხვი number იყო. C#-ში თითოეულ საქმეს თავისი ყუთი აქვს:

C# ტიპი რას ინახავს მაგალითი JS-ში
int მთელი რიცხვი 16, -5, 2026 number
double ათწილადი 1.78, 3.14 number
decimal ფული — ზუსტად 19.99m number
bool კი / არა true, false boolean
char ერთი სიმბოლო 'A' — ერთმაგი ბრჭყალი —
string ტექსტი "გამარჯობა" — ორმაგი ბრჭყალი string

decimal-ის რიცხვს ბოლოში m უწერია (25.50m) — ასე იცის C#-მა, რომ ფულია.
