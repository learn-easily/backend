# ლექციები

ყველა ლექციის პრეზენტაცია და კონსპექტი ერთ ადგილას, ერთ ძრავზე.

**საიტი:** https://learn-easily.github.io/backend/

## სტრუქტურა

```
engine/                      ერთი ძრავი ყველა ლექციისთვის
  engine.js · engine.css · theme-light.css
  index.html                 მთავარი გვერდის შაბლონი (ქარდები, ძებნა)
  study.html                 კონსპექტის გვერდის შაბლონი
courses/
  <კურსი>/course.json        {"title", "order"} — ერთი კურსი = ერთი ჩანართი მთავარ გვერდზე
  <კურსი>/<NN-slug>/
    deck.html                სლაიდები; ყოველ სლაიდში — <aside class="study"> (სტუდენტის ახსნა, markdown)
    lecture.json             {"title", "why", "outcomes", "review"}
    classwork.md             კლასში დავალება
    homework.md              საშინაო (+ ამოხსნა, რომელიც მხოლოდ შემდეგ ლექციაზე ჩანს)
    materials/               არასავალდებულო — ფაილები ჩამოსატვირთად (მაგ. SQL)
build.py                     აწყობს ყველაფერს → index.html + <კურსი>/<ლექცია>/ (root-ში, GitHub Pages ამას აჩვენებს)
```

| კურსი | საქაღალდე |
|---|---|
| C# | `courses/csharp/` |
| EF Core | `courses/efcore/` |
| ASP.NET | `courses/aspnet/` |
| SQL | `courses/sql/` |
| DevOps | `courses/devops/` |

## ლექციაზე

1. გახსენი საიტი, აირჩიე ლექცია → **▶ პრეზენტაცია**.
2. გადაიტანე პროექტორზე, დააჭირე `F`.
3. `P` — **კონსპექტი** ცალკე ფანჯარაში. ის სლაიდებს მიჰყვება; კონსპექტში „სლაიდი N“-ზე დაჭერა პრეზენტაციას იმ სლაიდზე გადაიყვანს.
4. ნავიგაცია ისრებით: `→` შემდეგი, `←` წინა.

სხვა კლავიშები: `O` ყველა სლაიდი · `A` სლაიდის ყველა ნაბიჯი · `Shift+→` შემდეგი სლაიდი. ასოები ქართულ განლაგებაზეც მუშაობს.

სტუდენტები კონსპექტს სახლში ქარდიდან ხსნიან: **📖 კონსპექტი**.

## ლექციის სტრუქტურა

ახალი ფორმატის ლექციაში ყველა ნაწილი სავალდებულოა — `deck.html`-ში ცხადი tag-ებით, რომლებსაც build სლაიდებად აქცევს:

| tag | სლაიდი | საიდან |
|---|---|---|
| `<lecture-review/>` | გამეორება — წინა ლექციის კითხვები | წინა ლექციის `lecture.json` → `review` |
| `<lecture-homework-review/>` | წინა საშინაოს განხილვა + ამოხსნა | წინა ლექციის `homework.md` |
| `<lecture-intro/>` | დღის თემა: რატომ გჭირდებათ, რას შეძლებთ | `lecture.json` → `why`, `outcomes` |
| `<lecture-classwork/>` | კლასში დავალება | `classwork.md` |
| `<lecture-check/>` | შევამოწმოთ — ამ ლექციის კითხვები | `lecture.json` → `review` |
| `<lecture-homework/>` | საშინაო (ამოხსნის გარეშე) | `homework.md` |

თეორია და პრაქტიკული ჩვენება — ჩვეულებრივი სლაიდებია მათ შორის. ერთი და იგივე კითხვები ლექციის ბოლოს „შევამოწმოთ“-ში ჩანს და შემდეგი ლექციის დასაწყისში „გამეორებაში“ — ერთხელ იწერება. build შეჩერდება, თუ ახალი ფორმატის ლექციას რომელიმე ნაწილი აკლია. ნიმუში: `courses/aspnet/03-dto-mapping/`.

`classwork.md` / `homework.md`: `# სათაური`, ქვესათაური, მერე `## მოთხოვნები` (ან `## ნაბიჯები`), `## ✓ მზადაა, როცა`, `## ⭐ ბონუსი`, `## 💡 …` (მხოლოდ კონსპექტში), `## ამოხსნა` (მხოლოდ homework-ში; ჩანს შემდეგ ლექციაზე).

## კონსპექტის ფორმატი

`<aside class="study">` — ჩვეულებრივი markdown (სათაურები, სიები, ცხრილები). სლაიდი ტექსტის გარეშე წინა ბლოკს უერთდება. დამატებითი ბლოკები:

````
```csharp Controllers/ProductsController.cs     ← კოდი, სათაურით და „კოპირება“ ღილაკით
```prompt AI-სთვის                              ← პრომპტი ChatGPT/Claude-ისთვის, კოპირდება
```check                                        ← „შეამოწმე თავი“: ? კითხვა / = პასუხი
```terms                                        ← ტერმინები: ტერმინი — ახსნა
```note · ```warn · ```tip                      ← გამოყოფილი შენიშვნა
````

ძველი ლექციების `<aside class="notes">` (ლექტორის სცენარი) აღარ ქვეყნდება — ახალ ფორმატზე გადაყვანისას შიგთავსი კონსპექტში გადადის.

## ახალი ლექცია

1. `courses/<კურსი>/<NN-slug>/` — `deck.html`, `lecture.json`, `classwork.md`, `homework.md`.
2. ახალი კურსისთვის — `courses/<კურსი>/course.json`.
3. `python3 build.py`, შემდეგ commit + push `main`-ზე. ერთ წუთში საიტზე ახალი ქარდი გამოჩნდება.

> `csharp/`, `efcore/`, `aspnet/`, `sql/`, `devops/` და root-ის `index.html` ბილდის შედეგია — ხელით არ შეცვალო, შეცვალე `courses/` და გაუშვი ბილდი.

## ლოკალურად

```bash
python3 -m venv .venv && .venv/bin/pip install pygments markdown   # ერთხელ
.venv/bin/python build.py                                          # ყველაფერი → root
.venv/bin/python build.py aspnet/03                                # მხოლოდ ერთი ლექცია
python3 -m http.server 8000                                        # http://localhost:8000
```
