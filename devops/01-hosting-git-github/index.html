ახალი ფიჩა — როგორ არ გავტეხო main?

🌿 Branch

ისტორიის პარალელური ხაზი. main ხელუხლებელი რჩება

🧪 ექსპერიმენტი

არ გამოვიდა? branch-ს წაშლი — main-ს არაფერი მოსვლია

👥 გუნდი

ყველა თავის branch-ზე მუშაობს და ერთმანეთს არ უშლის

Merge — შტოს დაბრუნება მთავარში

Git Bash$ git switch main$ git merge feature/contactsMerge made by the 'ort' strategy. index.html | 12 ++++++++++++$ git branch -d feature/contacts
① გადადი იქ, სადაც უნდა შეერწყას (main)
② merge — branch-ის ცვლილებები main-ში გადმოდის
③ branch აღარ გვჭირდება — ვშლით
როცა Git ვერ წყვეტს

Conflict — ეს შეცდომა არ არის

index.html<<<<<<< HEAD<h1>გიორგის პორტფოლიო</h1>=======<h1>გიორგი ბერიძე — დეველოპერი</h1>>>>>>>> feature/title
HEAD — რაც main-ზე წერია
feature/title — რაც branch-ზე წერია
