დღის თემა: პირობები — if, else, switch

სლაიდი 4

წინა ლექციის პროგრამა ყოველთვის ერთსა და იმავეს აკეთებდა — 2030 წელს დაბადებულსაც კი უთვლიდა ასაკს. ნამდვილი აპი კი სულ ამოწმებს: პაროლი სწორია? ფული საკმარისია? თამაში დამთავრდა? დღეს პროგრამა ისწავლის გადაწყვეტილების მიღებას — და ბოლოს საკუთარ ტექსტურ თამაშს დავწერთ.

ლექციის ბოლოს შეძლებ:

  • შედარება და bool: ==, !=, >, <=, &&, ||, !
  • if / else if / else, ჩადგმული if და ტექსტის შედარება
  • ? :, switch და თანამედროვე switch expression — რომელი როდის
  • რით განსხვავდება C#-ის პირობები JS-ისგან

შესავალი

პრობლემა: პროგრამა ყოველთვის ერთნაირად იქცევა

სლაიდი 5

წინა ლექციის ანკეტაში დაბადების წლად 2030 რომ შეიყვანო, პროგრამა მშვიდად დაგიწერს: „შენ ხარ -4 წლის“. ის ვერაფერს ამოწმებს — უბრალოდ ითვლის.

ნამდვილი აპები კი სულ ამოწმებენ:

  • 🔐 პაროლი სწორია? → შემოუშვი · არა → „არასწორი პაროლი“
  • 💳 ბალანსი საკმარისია? → გადაიხადე · არა → უარი
  • 🎮 სიცოცხლე 0-ია? → Game Over · არა → თამაში გრძელდება

Backend-ის ნახევარი სწორედ ესაა: შეამოწმე → გადაწყვიტე. ყოველ კითხვას პასუხად აქვს „კი“ ან „არა“ — და ამისთვის C#-ში სპეციალური ტიპი გვაქვს: bool.

1 · bool და შედარება

ნაწილი 1 · bool და შედარება

სლაიდი 6

ყოველი გადაწყვეტილება იწყება კითხვით, რომლის პასუხია true ან false.

შედარება აბრუნებს bool-ს

სლაიდი 7
Program.cs
int age = 16;string name = "ნიკა"; bool isAdult = age >= 18;bool isSixteen = age == 16;bool isNotAna = name != "ანა"; Console.WriteLine(isAdult);     // FalseConsole.WriteLine(isSixteen);   // TrueConsole.WriteLine(isNotAna);    // True

age >= 18 — ეს კითხვაა, და მისი პასუხი (true ან false) bool ცვლადში ჩაიდება.

ოპერატორი კითხვა
== ტოლია?
!= არ უდრის?
> < მეტია? ნაკლებია?
>= <= მეტია ან ტოლი? ნაკლები ან ტოლი?
⚠️

= — „ჩადე“ (მინიჭება). == — „ტოლია?“ (შედარება). ორი სულ სხვა რამ!

და, ან, არა: && · || · !

სლაიდი 8
✈️ ფრენა
bool hasTicket = true;bool hasPassport = false;bool isVip = true; bool canFly = hasTicket && hasPassport;   // Falsebool fastLane = isVip || hasTicket;       // Truebool noTicket = !hasTicket;               // False
  • && — და: true, როცა ორივე true-ა.
  • || — ან: true, როცა ერთი მაინც true-ა.
  • ! — არა: აბრუნებს — true ↔ false.

JS-ში ზუსტად ასე იყო.

2 · if / else

ნაწილი 2 · if / else: პროგრამა იღებს გადაწყვეტილებას

სლაიდი 9

აქ JS-ის ცოდნა თითქმის სრულად გამოგადგება.

if — 95% იგივეა

სლაიდი 10
JavaScript
let age = 17; if (age >= 18) {  console.log("შეგიძლია მართვის მოწმობის აღება");} else {  console.log("ჯერ ადრეა");}
C#
int age = 17; if (age >= 18){    Console.WriteLine("შეგიძლია მართვის მოწმობის აღება");}else{    Console.WriteLine("ჯერ ადრეა");}

განსხვავება მხოლოდ: int (let-ის ნაცვლად), Console.WriteLine და ფრჩხილები ახალ ხაზზე. ლოგიკა — იგივე.

ოპერატორი მნიშვნელობა
== · != ტოლია · არ უდრის
> < >= <= შედარება

ლოგიკური: && — და, || — ან, ! — არა.

ის 5%: სამი რამ, რაც JS-ისგან განსხვავდება

სლაიდი 11
  1. ⚖️ === არ არის. JS-ში "5" == 5 → true 😬, ამიტომ ===-ს წერდი. C#-ში ტიპები მკაცრია — == საკმარისია, "5" == 5 კი საერთოდ არ კომპილირდება.
  2. 🚫 Truthy / Falsy არ არის. JS: if (count) ✅ · C#: if (count) ❌ — პირობა მხოლოდ bool შეიძლება იყოს: if (count > 0).
  3. 🧱 ფრჩხილები — C#-ში { ჩვეულებრივ ახალ ხაზზე იწერება (სტილია, არა წესი).

სამივე ერთსა და იმავეს ამბობს: C# მკაცრია — და ამით გიცავს.

ქულა → შეფასება

სლაიდი 12
Program.cs
Console.Write("შეიყვანე ქულა (1-10): ");int score = int.Parse(Console.ReadLine()); if (score >= 9){    Console.WriteLine("ფრიადი! 🌟");}else if (score >= 7){    Console.WriteLine("კარგი");}else if (score >= 5){    Console.WriteLine("საშუალო");}else{    Console.WriteLine("მეტი ვარჯიში გვჭირდება");}

შემოწმება ზემოდან იწყება და ჩერდება პირველ სწორ პირობაზე. ქულა 8: 8 >= 9 ✗ → 8 >= 7 ✓ → „კარგი“ → stop.

🎢 ატრაქციონზე შეგიშვებენ?

სლაიდი 13

წესი: სიმაღლე მინიმუმ 130 სმ და (ასაკი 12+ ან მშობელთან ერთად).

Program.cs
int age = 11;int height = 135;bool withParent = true; if (height >= 130 && (age >= 12 || withParent)){    Console.WriteLine("მობრძანდით!");}else{    Console.WriteLine("სამწუხაროდ, ჯერ ვერა");}
  • && — ორივე უნდა იყოს true. || — საკმარისია ერთი.
  • ფრჩხილები — ჯერ შიგნით მოწმდება, როგორც მათემატიკაში.
  • 135 ≥ 130 ✓ · (11 ≥ 12 ✗ || true ✓) → მობრძანდით!
✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
withParent = false — რა დაიბეჭდება?
„სამწუხაროდ, ჯერ ვერა“ — ფრჩხილში ორივე false-ია, ამიტომ მთელი პირობა false

Program.cs
Console.Write("გიყვარს პროგრამირება? (კი/არა) ");string answer = Console.ReadLine().ToLower(); if (answer == "კი"){    Console.WriteLine("ჩვენი ადამიანი! 💜");}else if (answer == "არა"){    Console.WriteLine("ჯერ... 😉");}else{    Console.WriteLine("კი ან არა დაწერე");}

3 · switch

ნაწილი 3 · ბევრი ვარიანტი: ? : და switch

სლაიდი 16

როცა else if-ების ჯაჭვი ზედმეტად გრძელდება, C#-ს მოკლე გზები აქვს.

კიდევ ორი იარაღი: ternary და switch

სლაიდი 17
ლუწი თუ კენტი
Console.Write("რიცხვი: ");int n = int.Parse(Console.ReadLine()); string kind = n % 2 == 0 ? "ლუწი" : "კენტი";Console.WriteLine($"{n} — {kind}");

Ternary — მოკლე if: პირობა ? თუ კი : თუ არა. ზუსტად JS-ის მსგავსი. % 2 == 0 → იყოფა 2-ზე.

კვირის დღე
int day = int.Parse(Console.ReadLine()); switch (day){    case 6:    case 7:        Console.WriteLine("შაბათ-კვირა! 🎉");        break;    default:        Console.WriteLine("სასწავლო დღე");        break;}

switch — როცა ერთ ცვლადს ბევრ მნიშვნელობას ადარებ. break დაგავიწყდა? JS ჩუმად გადადის შემდეგ case-ზე; C# — შეცდომას გაჩვენებს.

  • default — ყველა სხვა შემთხვევა, როგორც ბოლო else.

switch expression — მოკლე და სუფთა

სლაიდი 19

თანამედროვე C#-ის ფორმა — JS-ში ასეთი რამ არ არის. გამოიყენე, როცა ერთი ცვლადიდან ერთი მნიშვნელობა უნდა მიიღო.

კვირის დღე
int day = int.Parse(Console.ReadLine()); string name = day switch{    1 => "ორშაბათი",    2 => "სამშაბათი",    3 => "ოთხშაბათი",    4 => "ხუთშაბათი",    5 => "პარასკევი",    6 or 7 => "შაბათ-კვირა 🎉",    _ => "ასეთი დღე არ არსებობს"}; Console.WriteLine(name);
  • ცვლადი წინ იწერება, მერე switch — შედეგი პირდაპირ ცვლადში ჩაიდება.
  • => — „მაშინ შედეგია…“. or — რამდენიმე მნიშვნელობა. _ — ყველა სხვა შემთხვევა (როგორც default).
  • ყოველ სტრიქონს ბოლოში მძიმე, მთელს — };.

შედარებაც შეიძლება — ქულა → შეფასება 7 ხაზში, 19-ის ნაცვლად:

ქულა → შეფასება
string grade = score switch{    >= 9 => "ფრიადი 🌟",    >= 7 => "კარგი",    >= 5 => "საშუალო",    _ => "მეტი ვარჯიში გვჭირდება"};

ზემოდან ქვემოთ მოწმდება და პირველივე სწორზე ჩერდება — ზუსტად როგორც else if-ების ჯაჭვი.

✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
int count = 3; if (count) { … } — რა მოხდება?
შეცდომა: პირობა მხოლოდ bool შეიძლება იყოს → if (count > 0)
რა განსხვავებაა =-სა და ==-ს შორის?
= — ჩადე (მინიჭება) · == — ტოლია? (შედარება, აბრუნებს bool-ს)
true && false და true || false — რა გამოვა?
&& → false (ორივე უნდა იყოს true) · || → true (საკმარისია ერთი)
ქულა 8-ზე if (score >= 5) … else if (score >= 7) … — რომელი შესრულდება?
პირველი (>= 5) — if პირველივე სწორ პირობაზე ჩერდება, ამიტომ რიგს აქვს მნიშვნელობა
switch expression-ში რას ნიშნავს _?

სლაიდი 26

დაიმახსოვრე:

  1. შედარება (==, !=, >, <…) აბრუნებს bool-ს. = — ჩადე, == — ტოლია?
  2. if / else if / else — ზემოდან ქვემოთ მოწმდება და პირველივე სწორ პირობაზე ჩერდება. პირობა — მხოლოდ bool.
  3. switch — ერთი ცვლადი, ბევრი ვარიანტი; break სავალდებულოა. switch expression — როცა შედეგი ერთი მნიშვნელობაა; _ = ყველა სხვა.
