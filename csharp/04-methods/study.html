მეთოდი — კოდის ნაწილი, რომელსაც სახელი აქვს. ერთხელ წერ, მერე სახელით იძახებ — რამდენჯერაც გინდა. JS-ში ამას ფუნქცია ერქვა.

გამეორება

გავიხსენოთ წინა ლექცია

სლაიდი 2

ლექცია 3 — ციკლები და მასივები. ახალ თემამდე ვამოწმებთ, რა დაგვამახსოვრდა. ჯერ თვითონ უპასუხე, მერე გახსენი პასუხი. თუ რომელიმე გაგიჭირდა, წინა ლექციის კონსპექტს გადახედე.

✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
როდის for და როდის while?
ვიცით, რამდენჯერ → for · არ ვიცით (მაგ. სანამ პაროლს არ გამოიცნობს) → while
რით განსხვავდება do-while while-ისგან?
do-while ერთხელ აუცილებლად სრულდება — პირობას ბოლოს ამოწმებს
int[] a = { 4, 8, 15 }; — რა არის a[1] და a.Length?
a[1] → 8 (ინდექსი 0-დან) · a.Length → 3
for (int i = 0; i <= a.Length; i++) — რა არის შეცდომა?
<= → ბოლო ბრუნზე a[a.Length] → IndexOutOfRangeException. სწორია i < a.Length
break და continue — რა განსხვავებაა?
break — ციკლიდან გამოდის · continue — მხოლოდ ამ ბრუნს ტოვებს

საშინაოს განხილვა

სლაიდი 3

წინა ლექციის საშინაო: „გამოიცანი რიცხვი“ 2.0. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • „გამოიცანი რიცხვი“ შენ თვითონ დაწერე — სლაიდში ჩაუხედავად
  • მაქსიმუმ 7 ცდა, მერე „Game Over“ და ჩაფიქრებული რიცხვი
  • ყოველი ვარაუდი ჩაწერე მასივში int[] history = new int[7]; და თამაშის ბოლოს დაბეჭდე: შენი ცდები: 50 75 63
  • თამაშის ბოლოს: „კიდევ ითამაშებ? (კი/არა)“ — do-while-ით, „კი“-ზე თავიდან იწყება

ამოხსნა

Program.cs
string again;do{    int secret = Random.Shared.Next(1, 101);    int[] history = new int[7];    int guess = 0;    int tries = 0;    while (guess != secret && tries < 7)    {        Console.Write($"ცდა {tries + 1}/7: ");        guess = int.Parse(Console.ReadLine());        history[tries] = guess;        tries++;        if (guess < secret) Console.WriteLine("მეტია ⬆");        else if (guess > secret) Console.WriteLine("ნაკლებია ⬇");    }    Console.WriteLine(guess == secret ? $"🎉 გამოიცანი {tries} ცდაში!" : $"Game Over! ჩაფიქრებული იყო {secret}");    Console.Write("შენი ცდები: ");    for (int i = 0; i < tries; i++)    {        Console.Write(history[i] + " ");    }    Console.WriteLine();    Console.Write("კიდევ ითამაშებ? (კი/არა) ");    again = Console.ReadLine();} while (again == "კი");
💡

ისტორიას foreach-ით არ ვბეჭდავთ: 3 ცდაში თუ გამოიცანი, მასივის დანარჩენი 4 ადგილი ნულებია. ამიტომ for მხოლოდ tries-მდე მიდის. history[tries] = guess; — tries++-მდე, რომ პირველი ვარაუდი ინდექს 0-ზე ჩაიწეროს.

დღის თემა: მეთოდები — საკუთარი ბრძანებები

სლაიდი 4

პროგრამები იზრდება: ერთი და იგივე კოდი სამ ადგილასაა კოპირებული, შეცდომა სამჯერ უნდა გაასწორო, 300 ხაზში კი ვეღარ პოულობ, სად რა ხდება. დღეს ვისწავლით მეთოდებს — კოდს სახელს ვარქმევთ, ერთხელ ვწერთ და სადაც გინდა ვიძახებთ. ბოლოს „გამოიცანი რიცხვს“ მეთოდებით გადავწერთ.

ლექციის ბოლოს შეძლებ:

  • მეთოდის გამოცხადება და გამოძახება: void, პარამეტრები, return
  • მასივი პარამეტრად: Average(int[] numbers)
  • scope: რატომ არ ჩანს მეთოდის ცვლადი გარეთ; default პარამეტრები
  • განმეორებადი კოდის მეთოდად გადაქცევა და კარგი სახელის შერჩევა

სლაიდი 20

დაიმახსოვრე:

  1. მეთოდი — სახელიანი კოდის ნაწილი. void — უბრალოდ აკეთებს; int, bool, double… — პასუხს აბრუნებს return-ით.
  2. მონაცემი მეთოდში შედის პარამეტრით, შედეგი გამოდის return-ით. მეთოდის ცვლადები გარეთ არ ჩანს.
  3. კოდი მეორდება? → მეთოდი. რაც ასლებში იცვლება → პარამეტრი.
  4. სახელი — PascalCase, ზმნით, ერთი საქმე.
