სლაიდი 1

ლექცია 10 — აბსტრაქცია და ინტერფეისი. ახალ თემამდე ვამოწმებთ, რა დაგვამახსოვრდა. ჯერ თვითონ უპასუხე, მერე გახსენი პასუხი. თუ რომელიმე გაგიჭირდა, წინა ლექციის კონსპექტს გადახედე.

✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი

საშინაოს განხილვა

სლაიდი 3

წინა ლექციის საშინაო: ⚽ ფეხბურთის კლუბი · ნაწილი 5 — მწვრთნელი და ხელფასები. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • Player → abstract; Rating() → abstract int Rating() (პოზიციები თავად ითვლიან: უნარი + Stamina / 5)
  • interface IPayable — int Salary(). Player : IPayable — ხელფასი Price / 20
  • ახალი კლასი Coach : IPayable — მოთამაშე არ არის: Name, Level (1–5), Salary() → Level * 2000, Bonus() → Level * 10
  • Club მწვრთნელს კონსტრუქტორში იღებს; Strength() მწვრთნელის Bonus()-საც ითვლის
  • Club.PaySalaries() — IPayable[] payroll: ყველა მოთამაშე + მწვრთნელი → ჯამი; ფული არ ჰყოფნის → „💸 კრიზისი“ და false, თორემ ბიუჯეტს აკლდება
  • Main-ში: ორი კლუბი, მატჩი, ორივე იხდის ხელფასს

დღის თემა

დღის თემა: OOP შეჯამება: პროექტი ნულიდან

სლაიდი 4

ოთხივე პრინციპი ცალ-ცალკე იცით. ნამდვილ პროექტში კი ისინი ერთად მუშაობს — და მთავარი ისაა, როგორ ფიქრობ, სანამ კოდს დაწერ. დღეს ჯერ ერთად ავაწყობთ გადახდის სისტემას ნულიდან, ხუთი კითხვით, მერე კი თქვენ თვითონ დაწერთ ზოოპარკს. ეს ყველაფერი შემდეგი ლექციის ტესტისთვისაც მოგამზადებთ.

ლექციის ბოლოს შეძლებ:

  • OOP პროექტის დაგეგმვა ხუთი კითხვით: კლასები, „არის“, „შეუძლია“, დაცვა, განსხვავება
  • გადახდის სისტემა: abstract Payment, IRefundable, დაცული მონაცემები
  • ზოოპარკი — საკუთარი OOP პროექტი ოთხივე პრინციპით
  • მზადება ტესტისთვის

შესავალი

💡 გავიხსენოთ: OOP — ოთხი პრინციპი

სლაიდი 5
  1. 🛡️ ინკაფსულაცია — private ველი, { get; private set; }, property წესით; მონაცემი იცვლება მხოლოდ მეთოდებით.
  2. 🧬 მემკვიდრეობა — class B : A, : base(...), protected; მხოლოდ ერთი მშობელი.
  3. 🎭 პოლიმორფიზმი — virtual / override, base.Method(), override ToString(); მშობლის ტიპის მასივი და ერთი ციკლი.
  4. 🎨 აბსტრაქცია — abstract კლასი და მეთოდი; interface — „შეუძლია“, ბევრი ერთ კლასს.

💡 როგორ ვფიქრობთ: OOP პროექტი ხუთი კითხვით იწყება

სლაიდი 6
  1. ვინ / რა? — დავალების არსებითი სახელები → კლასები.
  2. ვინ „არის“ ვინ? — „ბარათით გადახდა არის გადახდა“ → მემკვიდრეობა.
  3. რა „შეუძლია“ ზოგს? — „ზოგს შეუძლია თანხის დაბრუნება“ → ინტერფეისი.
  4. რა უნდა დავიცვათ? — „თანხა უარყოფითი არ არის“, „ბარათის ნომერი დამალულია“ → private და წესები.
  5. რა განსხვავდება? — „თითოეული თავისებურად იხდის“ → abstract მეთოდი და override.

🧩 დავალება: ონლაინ მაღაზიის სალარო

სლაიდი 8

მოთხოვნები:

  • მომხმარებელი იხდის ბარათით, ნაღდით ან ციფრული საფულით.
  • თანხა უარყოფითი ვერ იქნება.
  • ბარათის ნომრიდან ჩანს მხოლოდ ბოლო 4 ციფრი.
  • საფულეში ფული თუ არ ჰყოფნის — გადახდა არ ხერხდება.
  • ბარათით და საფულით გადახდილი თანხა ბრუნდება, ნაღდი — არა.
  • სალარო ყველა გადახდას ერთი ციკლით ამუშავებს.

ხუთი კითხვა:

  1. კლასები: Payment, CardPayment, CashPayment, WalletPayment.
  2. ბარათით გადახდა არის გადახდა → abstract class Payment.
  3. თანხის დაბრუნება შეუძლია ზოგს → interface IRefundable.
  4. დავიცვათ: თანხა, ბარათის ნომერი, ბალანსი → private.
  5. თითოეული თავისებურად იხდის → abstract bool Pay().

internal class CardPayment : Payment, IRefundable{    private string cardNumber;     public CardPayment(decimal amount, string number) : base(amount)    {        cardNumber = number;    }     public string Masked()    {        return "**** " + cardNumber.Substring(cardNumber.Length - 4);    }     public override bool Pay()    {        Console.WriteLine($"💳 ბარათი {Masked()} → {Amount} ₾");        return true;    }     public void Refund()    {        Console.WriteLine($"↩️ {Amount} ₾ დაბრუნდა ბარათზე {Masked()}");    }}
  • 🛡️ ბარათის ნომერი — private ველი, property-იც კი არა. გარედან ვერავინ წაიკითხავს.
  • Substring(start) — string-ის მეთოდი: ტექსტი start პოზიციიდან ბოლომდე. Length - 4 → ბოლო ოთხი ციფრი. ყველაფერი ობიექტია!
  • 🎭 override Pay() — თავისებურად; 🎨 Refund() — ხელშეკრულება შესრულდა.

internal class WalletPayment : Payment, IRefundable{    public decimal Balance { get; private set; }     public WalletPayment(decimal amount, decimal balance) : base(amount)    {        Balance = balance;    }     public override bool Pay()    {        if (Balance < Amount)        {            Console.WriteLine($"❌ საფულეში მხოლოდ {Balance} ₾ — არ ჰყოფნის");            return false;        }         Balance -= Amount;        Console.WriteLine($"📱 საფულე → {Amount} ₾ (დარჩა {Balance} ₾)");        return true;    }     public void Refund()    {        Balance += Amount;        Console.WriteLine($"↩️ {Amount} ₾ დაბრუნდა საფულეში ({Balance} ₾)");    }}
