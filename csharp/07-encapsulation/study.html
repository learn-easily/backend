წინა ლექციის საშინაო: ⚽ ფეხბურთის კლუბი · ნაწილი 1 — პენალტები. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • Console App FootballClub, კლასი Player (Player.cs): Name, Shot (დარტყმა 0–100), Reflex (მეკარის რეაქცია 0–100), Stamina (თავიდან 100) — კონსტრუქტორით Player(string name, int shot, int reflex)
  • Program-ში static void Train(Player p) — Shot +5 (მაქს. 100), Stamina −20 (მინ. 0)
  • Program-ში static bool Penalty(Player shooter, Player keeper) — გოლის შანსი: shooter.Shot - keeper.Reflex / 2; შემსრულებელს Stamina −5
  • Main-ში: Player[] shooters — 3 მოთამაშე, ერთი მეკარე. ერთ-ერთი ივარჯიშოს, მერე 5 პენალტი — შემსრულებლები რიგრიგობით; ყოველი დარტყმა იბეჭდება, ბოლოს — „შედეგი: 3/5“

წინა ლექციის ბოლოს ნახეთ: knight.Health = 99999; კომპილირდება, TakeDamage(-50) კი გმირს კურნავს. ნებისმიერ ადგილას შეიძლება ობიექტის გაფუჭება — და ბაგს ვერ იპოვი. დღეს ვისწავლით მონაცემის დამალვას (private), property-ს წესებით და private set-ს — ისე, რომ გმირი მხოლოდ საკუთარი მეთოდებით იცვლებოდეს. არენას კი წამლები დაემატება.

  • public და private: ვინ ხედავს კლასის წევრს; ველი (field)
  • property get/set-ით და წესით; value; auto-property
  • { get; private set; } — გარედან მხოლოდ წაკითხვა
  • მეთოდები, როგორც ერთადერთი „კარი“: TakeDamage, Heal, UsePotion
