ცვლადში რიცხვს და ტექსტს უკვე ინახავ. დღეს ვისწავლით ცვლადში მეთოდის შენახვას — და ბოლოს ამით ავაწყობთ თამაშს, სადაც ბოტს ებრძვი.

დღის თემა: დელეგატები — მეთოდი, როგორც მნიშვნელობა

სლაიდი 2

ცვლადში რიცხვს და ტექსტს უკვე ინახავთ. დღეს ვისწავლით ცვლადში მეთოდის შენახვას — რომ ერთმა მეთოდმა ბევრი სხვადასხვა რამ გააკეთოს, კლასს კი ქცევა გარედან მივცეთ. ლექციის ბოლოს ამ ცოდნით ავაწყობთ თამაშს: შენ ებრძვი ბოტს.

ლექციის ბოლოს შეძლებ:

  • მეთოდის შენახვა ცვლადში და ლამბდის დაწერა: x => x * 2
  • Action და Func — რომელი როდის
  • მეთოდისთვის პირობის გადაცემა: ერთი Filter ბევრი მეთოდის ნაცვლად
  • += და ?.Invoke() — ერთ მოვლენაზე რამდენიმე რეაქცია
  • კონსოლის თამაში „შენ vs ბოტი“ დელეგატებით

კონსოლის თამაში: შენ vs ბოტი. ყოველ რაუნდში ირჩევ სვლას — დარტყმა, ძლიერი დარტყმა ან განკურნება. ბოტი თავისით წყვეტს.

ამისთვის ოთხი იარაღი გვჭირდება — ოთხივეს დღეს ვისწავლით:

  1. Action · Func — მეთოდი ცვლადში
  2. ქცევა გარედან — ერთი კლასი, ბევრი სხვადასხვა ქცევა
  3. პირობის გადაცემა — ერთი მეთოდი, ბევრი წესი
  4. += — ერთ მოვლენაზე ბევრი რეაქცია

ახალი პირობა („ზუსტად 100“, „ლუწი“) → ახალი მეთოდი → კიდევ ერთი ასლი. ასეთი კოდი სწრაფად იზრდება, და თუ ერთ ადგილას შეცდომას იპოვი, ყველა ასლში უნდა გაასწორო.

იდეა: წესიც გადავცეთ მეთოდს

რა იქნება, თუ მეთოდს მივაწვდით თვითონ წესს — „აი, ასე შეამოწმე“?

Action და Func — ორი მზა ტიპი

სლაიდი 10

Action ასრულებს · Func აბრუნებს.

ტიპი იღებს აბრუნებს მაგალითი
Action არაფერს — () => Console.WriteLine("hi")
Action<string> string — name => Console.WriteLine(name)
Func<int> არაფერს int () => 42
Func<int, bool> int bool n => n % 2 == 0
Func<int, int, int> int, int int (a, b) => a + b
💡

Func-ში ბოლო ტიპი ყოველთვის ის არის, რასაც აბრუნებს. Func<int, bool> — იღებს int-ს, აბრუნებს bool-ს.

Action და Func მოქმედებაში

სლაიდი 11

Console.OutputEncoding = System.Text.Encoding.UTF8; Action<string> print = text => Console.WriteLine(text);Func<int, int, int> add = (a, b) => a + b;Func<int, bool> isEven = n => n % 2 == 0; print("C# მაგარია");            // C# მაგარიაConsole.WriteLine(add(3, 4));    // 7Console.WriteLine(isEven(10));   // TrueConsole.WriteLine(isEven(7));    // False

სამი ცვლადი, თითოეულში — მეთოდი. ცვლადს ვიძახებთ ზუსტად ისე, როგორც ჩვეულებრივ მეთოდს: add(3, 4).

🤖 Action და Func — ვარჯიში
ვსწავლობ C#-ში Action-ს და Func-ს. მომეცი 5 მარტივი ლამბდა (მაგ. x => x * 2) და მე ვეცდები ვთქვა, რა ტიპის ცვლადში ჩაიწერება თითოეული (Action, Action<string>, Func<int, int> ...). პასუხები მერე მაჩვენე, როცა ვუპასუხებ. ქართულად, 15 წლის მოსწავლისთვის.

გამოიცანი: რომელ ცვლადში ჩაიწერება?

სლაიდი 12
✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
() => Console.WriteLine("ბიპ")
Action — არაფერს იღებს, არაფერს აბრუნებს
x => x * x (x — int)
Func<int, int> — იღებს int-ს, აბრუნებს int-ს

age => age >= 18
Func<int, bool> — შედარება ყოველთვის bool-ს აბრუნებს

Func<int> — არაფერს იღებს, აბრუნებს შემთხვევით რიცხვს (კამათელი 🎲)

class Button{    public string Text;     public void Click()    {        if (Text == "Jump")            Console.WriteLine("🦘 მოთამაშე ხტება!");        else if (Text == "Shoot")            Console.WriteLine("🔫 პიუ-პიუ!");        else if (Text == "Pause")            Console.WriteLine("⏸ პაუზა");    }}

ახალი ღილაკის დასამატებლად Button კლასი უნდა შეცვალო — კიდევ ერთი else if. 50 ღილაკი → 50 else if ერთ მეთოდში.

ღილაკმა არ უნდა იცოდეს, რას აკეთებს. მისი საქმეა მხოლოდ თქვას: „დამაჭირეს!“ — დანარჩენი გარედან უნდა მოვიდეს.

გადაწყვეტა: ღილაკი დელეგატით

Program.cs
Button jump = new Button { Text = "Jump" };Button shoot = new Button { Text = "Shoot" }; jump.OnClick = () => Console.WriteLine("🦘 მოთამაშე ხტება!");shoot.OnClick = () => Console.WriteLine("🔫 პიუ-პიუ!"); jump.Click();shoot.Click();

List<int> scores = new List<int> { 45, 92, 13, 78, 100, 5, 67 }; Print(Filter(scores, s => s >= 80));      // 92, 100Print(Filter(scores, s => s < 20));       // 13, 5Print(Filter(scores, s => s == 100));     // 100Print(Filter(scores, s => s % 2 == 0));   // 92, 78, 100 static List<int> Filter(List<int> list, Func<int, bool> condition){    List<int> result = new List<int>();     foreach (int s in list)        if (condition(s)) result.Add(s);     return result;} static void Print(List<int> list) => Console.WriteLine(string.Join(", ", list));
  • Func<int, bool> condition — მეორე პარამეტრი პირობაა: იღებს რიცხვს, აბრუნებს true/false-ს.
  • if (condition(s)) — Filter-მა არ იცის, რა პირობაა. რაც მოვიდა, იმას ამოწმებს.
  • ახალი პირობა → ერთი ახალი ხაზი, არა ახალი მეთოდი. ნაწილი 1-ის ორი მეთოდი ერთმა შეცვალა.

s condition(s) შედეგი

92 92 >= 80 → true დაამატე

100 true დაამატე

ლამბდა ერთხელ გადავეცით, Filter-მა კი 7-ჯერ გამოიძახა. შედეგი: [92, 100].

Action onLevelUp = null; onLevelUp += () => Console.WriteLine("🔊 ხმა: ტა-და!");onLevelUp += () => Console.WriteLine("✨ ეფექტი: ნაპერწკლები");onLevelUp += () => Console.WriteLine("💾 თამაში შენახულია"); onLevelUp();   // სამივე შესრულდება

ერთ დელეგატში შეიძლება რამდენიმე მეთოდი ინახებოდეს. გამოძახებისას ყველა სრულდება, იმ რიგით, რა რიგითაც დაემატა.

რას აკეთებს
= ანაცვლებს — ძველი იკარგება
+= ამატებს ბოლოში
-= აშორებს
⚠️

+=-ის ნაცვლად = თუ დაწერე, წინა ყველა რეაქცია წაიშლება — და მხოლოდ ბოლო დარჩება.

ხაფანგი: თუ არავინ გამოიწერა?

სლაიდი 22
❌ პროგრამა ვარდება
Action onLevelUp = null;onLevelUp();   // NullReferenceException
✅ უსაფრთხოდ
Action onLevelUp = null;onLevelUp?.Invoke();   // არაფერი ხდება

ცარიელი დელეგატი null-ია. null-ის გამოძახება პროგრამას აგდებს.

?.Invoke() ნიშნავს: „თუ ცარიელი არ არის — გამოიძახე, თუ ცარიელია — გამოტოვე“.

💡

კლასის შიგნით მოვლენას ყოველთვის ?.Invoke()-ით იძახებ: კლასმა არ იცის, ვინმე გამოიწერს თუ არა.

public class Fighter{    public string Name;    public int Health = 100;     public Func<int> ChooseMove;     // ტვინი: რომელ სვლას ირჩევს    public Action<int> OnDamaged;    // დამარტყეს (რამდენი)    public Action<int> OnHealed;     // განიკურნა (რამდენი)    public Action OnDied;            // დამარცხდა     public void TakeDamage(int amount)    {        Health -= amount;        if (Health < 0) Health = 0;         OnDamaged?.Invoke(amount);         if (Health == 0)            OnDied?.Invoke();    }     public void Heal(int amount)    {        Health += amount;        if (Health > 100) Health = 100;         OnHealed?.Invoke(amount);    }}
  • ეტაპი 2 — მოვლენები. OnDamaged, OnHealed, OnDied — Fighter მხოლოდ ამბობს, რა მოხდა. როგორ ვუპასუხოთ, ამას Program.cs წყვეტს.
  • ყველგან ?.Invoke() — შეიძლება ვინმე არ უსმენდეს.
  • ეტაპი 3 — ტვინი. Func<int> ChooseMove აბრუნებს სვლის ნომერს: 1 — დარტყმა, 2 — ძლიერი დარტყმა, 3 — განკურნება.

Fighter-ში არცერთი Console.WriteLine არ არის.

ბრძოლის კოდს არ აინტერესებს, ვინ წყვეტს — ის უბრალოდ იძახებს ChooseMove()-ს და იღებს 1-ს, 2-ს ან 3-ს. ეს იგივეა, რაც ნაწილი 3-ის ღილაკი: ქცევა გარედან მოდის.

Console.OutputEncoding = System.Text.Encoding.UTF8;Console.InputEncoding = System.Text.Encoding.UTF8; Random random = new Random(); Fighter player = new Fighter { Name = "შენ" };Fighter bot = new Fighter { Name = "ბოტი" }; player.ChooseMove = () =>{    Console.Write("1 - დარტყმა | 2 - ძლიერი | 3 - განკურნება: ");    string input = Console.ReadLine();     if (input == "2") return 2;    if (input == "3") return 3;    return 1;}; bot.ChooseMove = () =>{    if (bot.Health < 30) return 3;    // ცოტა სიცოცხლე → ვიკურნები    return random.Next(1, 3);         // სხვა დროს → 1 ან 2};

ერთი სვლა — DoMove

სლაიდი 31
Program.cs · DoMove (ფაილის ბოლოს)
static void DoMove(Fighter attacker, Fighter target, Random random){    int move = attacker.ChooseMove();     if (move == 1)    {        Console.WriteLine($"👊 {attacker.Name}: დარტყმა");        target.TakeDamage(random.Next(10, 21));    }    else if (move == 2)    {        Console.WriteLine($"🔥 {attacker.Name}: ძლიერი დარტყმა...");         if (random.Next(0, 2) == 0)            Console.WriteLine("   ❌ აცდა!");        else            target.TakeDamage(random.Next(25, 41));    }    else    {        Console.WriteLine($"🧪 {attacker.Name}: განკურნება");        attacker.Heal(random.Next(10, 26));    }}
სვლა რა ხდება
1 · დარტყმა 10–20 დაზიანება, ყოველთვის
2 · ძლიერი 25–40 დაზიანება, მაგრამ 50% შანსით აცდება
3 · განკურნება +10–25 HP
  • attacker.ChooseMove() — DoMove-მა არ იცის, ვინ ირჩევს. ერთი მეთოდი მოთამაშეზეც და ბოტზეც მუშაობს.
  • TakeDamage / Heal შიგნით ?.Invoke()-ს იძახებს → ეკრანზე იწერება ის, რაც მოვლენებზე გამოვიწერეთ.
⚠️

DoMove — static მეთოდია, ამიტომ ფაილის ბოლოში ჩაწერე, ყველა სხვა კოდის შემდეგ. Fighter კლასი კი ცალკე ფაილშია — თორემ შეცდომა CS8803 გამოვა.

🤖 თამაშის გაუმჯობესება
დავწერე C#-ში კონსოლის თამაში: Fighter კლასი Func<int> ChooseMove-ით (ტვინი) და Action<int> OnDamaged / OnHealed, Action OnDied მოვლენებით. მინდა თამაში გავაუმჯობესო, მაგრამ თვითონ დავწერო. მომეცი 3 იდეა (მაგ. ახალი სვლა, ბოტის ჭკვიანი ტვინი, ახალი მოვლენა) და თითოეულისთვის მხოლოდ მინიშნება, მზა კოდის გარეშე. ქართულად, 15 წლის მოსწავლისთვის.
