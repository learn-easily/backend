აბსტრაქცია და ინტერფეისი

წაიკითხე ლექციის შემდეგ, ან პრეზენტაციასთან ერთად: პრეზენტაციაში დააჭირე P და ეს გვერდი სლაიდებს გაჰყვება. კოდი და AI-ს პრომპტები კოპირდება ერთი დაჭერით.

ლექცია 9 — პოლიმორფიზმი. ახალ თემამდე ვამოწმებთ, რა დაგვამახსოვრდა. ჯერ თვითონ უპასუხე, მერე გახსენი პასუხი. თუ რომელიმე გაგიჭირდა, წინა ლექციის კონსპექტს გადახედე.

საშინაოს განხილვა

სლაიდი 3

წინა ლექციის საშინაო: ⚽ ფეხბურთის კლუბი · ნაწილი 4 — პირველი მატჩი. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • Player-ში virtual int Rating() (Stamina / 5) — ყოველი პოზიცია override-ით: უნარი + base.Rating()
  • Player-ში virtual void Train() (Tire(20)) — მეკარე ავარჯიშებს Reflex-ს, მცველი Defense-ს, თავდამსხმელი Shot-ს (+3, მაქს. 100) და მერე base.Train()
  • override ToString() — Player: „ნიკა ⭐ 96 ⚡ 100“; პოზიციები წინ ამატებენ 🧤 / 🛡️ / ⚽ + base.ToString()
  • Club-ში: int Strength() — ყველა Rating()-ის ჯამი; void TrainAll() — ვარჯიშობს, ვისაც Stamina 20+ აქვს; PrintSquad — Console.WriteLine(squad[i])
  • Program-ში static void PlayMatch(Club home, Club away) — გოლები: Random.Shared.Next(0, club.Strength() / 100 + 1). Main-ში ორი კლუბი: მატჩი → ერთი კლუბი ვარჯიშობს → განმეორებითი მატჩი

დღის თემა

დღის თემა: აბსტრაქცია და ინტერფეისი

სლაიდი 4

new Character(...) კომპილირდება — თამაშში კი „უბრალოდ პერსონაჟი“ არ არსებობს. ქურდს override დაავიწყდა — და კომპილატორი ჩუმადაა. მკურნალებს კი HealAlly სჭირდებათ, რომელიც არც Character-ს ეკუთვნის, არც ცალკე მშობელს. დღეს ვისწავლით abstract კლასს და მეთოდს, ინტერფეისს — და ოთხივე პრინციპით გავმართავთ საბოლოო ბრძოლას დრაკონთან.

ლექციის ბოლოს შეძლებ:

  • abstract class — კლასი-იდეა, რომლის ობიექტიც ვერ შეიქმნება
  • abstract მეთოდი — „ყველა შვილი ვალდებულია დაწეროს“; virtual vs abstract
  • interface — „შეუძლია“: IHealer, ILootable; ბევრი ინტერფეისი ერთ კლასს
  • abstract კლასი vs interface — „არის“ vs „შეუძლია“; ოთხივე პრინციპი ერთ თამაშში

💡 აბსტრაქცია: „ცხოველი“ — იდეაა

სლაიდი 6

არავის უნახავს „უბრალოდ ცხოველი“ — მხოლოდ ძაღლი, კატა, თევზი. „ცხოველი“ იდეაა, რომელიც ამბობს, რა აქვს ყველას საერთო. Character-იც ასეა.

  • რა — ჩანს: ყველა პერსონაჟი უტევს, Attack().
  • როგორ — დამალულია: თითოეულის საქმეა. ბრძოლის კოდს ეს არ აინტერესებს.

აბსტრაქცია — აჩვენე, რა შეუძლია ობიექტს; დამალე, როგორ. მანქანას პედლით მართავ — ძრავის შიგნით რა ხდება, არ გჭირდება.

⌨️ ერთი სიტყვა — abstract

💡 interface: მართვის მოწმობა

სლაიდი 14

ექიმი, მასწავლებელი, სტუდენტი — სხვადასხვა პროფესია („ვინ არის“). მართვის მოწმობა კი სამივეს შეიძლება ჰქონდეს — „შეუძლია მართოს“.

interface — ხელშეკრულება: „ვინც ამას ახორციელებს, ვალდებულია ეს მეთოდები ჰქონდეს“. „როგორ“ — თითოეულის საქმეა.

  • კლასს მხოლოდ ერთი მშობელი ჰყავს, ინტერფეისი კი ბევრი შეიძლება ჰქონდეს.
  • სახელს I-ით ვიწყებთ: IHealer, ILootable — მაშინვე ჩანს, რომ ინტერფეისია.
