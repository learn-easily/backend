კლასები და ობიექტები

წაიკითხე ლექციის შემდეგ, ან პრეზენტაციასთან ერთად: პრეზენტაციაში დააჭირე P და ეს გვერდი სლაიდებს გაჰყვება. კოდი და AI-ს პრომპტები კოპირდება ერთი დაჭერით.

სლაიდი 1

კლასები და ობიექტები

აქამდე მონაცემები (ცვლადები) და მოქმედებები (მეთოდები) ცალ-ცალკე იყო. დღეს მათ ერთად ვაერთიანებთ: კლასი — ნახაზი, ობიექტი — ამ ნახაზით შექმნილი ნამდვილი რამ.

გამეორება

გავიხსენოთ წინა ლექცია

სლაიდი 2

ლექცია 4 — მეთოდები — საკუთარი ბრძანებები. ახალ თემამდე ვამოწმებთ, რა დაგვამახსოვრდა. ჯერ თვითონ უპასუხე, მერე გახსენი პასუხი. თუ რომელიმე გაგიჭირდა, წინა ლექციის კონსპექტს გადახედე.

✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
რას ნიშნავს void მეთოდის სახელის წინ?
მეთოდი არაფერს აბრუნებს — უბრალოდ აკეთებს (მაგ. ბეჭდავს)
int Add(int a, int b) — რას იღებს და რას აბრუნებს?
იღებს ორ int-ს (a, b), აბრუნებს int-ს — return-ით
AddBonus(score); — მეთოდში value += 5 წერია. შეიცვლება score?
არა — მეთოდში ასლი შევიდა. შედეგი return-ით უნდა დააბრუნო: score = AddBonus(score);
void PrintLine(char symbol = '-') — რა მოხდება PrintLine();-ზე?
default მნიშვნელობა გამოიყენება — დაიბეჭდება --ებით
როდის ვაქცევთ კოდს მეთოდად?
როცა მეორდება ან ძალიან გრძელია; რაც ასლებში იცვლება — პარამეტრი ხდება

საშინაოს განხილვა

სლაიდი 3

წინა ლექციის საშინაო: კალკულატორი 2.0 — მეთოდებით. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • ახალი Console App: Calculator
  • სამი მეთოდი: double ReadDouble(string question), double Calculate(double a, double b, string op) (switch expression) და void PrintResult(double a, double b, string op, double result) — ფერით: 7 / 2 = 3.5
  • do-while მენიუ: გამოთვლის შემდეგ „კიდევ? (კი/არა)“
  • 0-ზე გაყოფა: Calculate-მდე შეამოწმე და დაბეჭდე გაფრთხილება
  • ძირითადი კოდი (მეთოდების ზემოთ) — 15 ხაზზე ნაკლები

💡

return op switch { … }; — switch expression მნიშვნელობას აბრუნებს, ამიტომ მისი შედეგი პირდაპირ return-ით შეგვიძლია დავაბრუნოთ, ცალკე ცვლადის გარეშე. PrintResult(a, b, op, Calculate(a, b, op)) — ჯერ Calculate სრულდება, მისი პასუხი კი PrintResult-ის მეოთხე პარამეტრი ხდება.

დღის თემა: კლასები და ობიექტები

სლაიდი 4

ერთი მოსწავლის სახელი, ასაკი და ქულა სამ ცალკე ცვლადშია — 30 მოსწავლე უკვე 90 ცვლადია და ერთი არასწორი ცვლადი მეთოდში ყველაფერს არევს. მოსწავლე, გმირი, პროდუქტი — ერთი „რამაა“ და ერთ ცვლადში უნდა ცხოვრობდეს. დღეს ვისწავლით საკუთარი ტიპების შექმნას — კლასებს, მათ მეთოდებს და კონსტრუქტორებს.

ლექციის ბოლოს შეძლებ:

  • კლასი და ობიექტი: class, property, new — ჯერ Program.cs-ში
  • მეთოდი კლასში: ობიექტი თავის მონაცემებს იცნობს
  • კონსტრუქტორი და მისი წესები; რამდენიმე კონსტრუქტორი — განსხვავებული პარამეტრებით
  • კლასის გადატანა ცალკე ფაილში

  • კლასი იწერება class Program-ის შემდეგ, იმავე namespace-ის შიგნით.
  • property — ობიექტის მონაცემი: Name, Age, Average. სახელი — დიდი ასოთი. { get; set; } — წაკითხვაც (get) და შეცვლაც (set) შეიძლება.
  • public — ჯერ უბრალოდ ვწერთ; რას ნიშნავს, OOP-ის ლექციაზე გავიგებთ.
  • = "" — სახელი დასაწყისში ცარიელი ტექსტია.
  • Student — ახალი ტიპი, ისევე როგორც int. new Student() — ახალი ობიექტი. nika.Name — „ნიკას სახელი“.
