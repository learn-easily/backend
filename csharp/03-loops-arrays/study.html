ციკლები და მასივები

კომპიუტერს ყველაზე კარგად ერთი რამ გამოსდის: ერთი და იმავეს დაუღალავად გამეორება. დღეს ვისწავლით ციკლებს (for, while, do-while, foreach) და მასივებს — ბევრი მონაცემი ერთ ცვლადში.

გამეორება

გავიხსენოთ წინა ლექცია

სლაიდი 2

ლექცია 2 — პირობები — if, else, switch. ახალ თემამდე ვამოწმებთ, რა დაგვამახსოვრდა. ჯერ თვითონ უპასუხე, მერე გახსენი პასუხი. თუ რომელიმე გაგიჭირდა, წინა ლექციის კონსპექტს გადახედე.

✅ შეამოწმე თავი დაფიქრდი, მერე გახსენი პასუხი
int count = 3; if (count) { … } — რა მოხდება?
შეცდომა: პირობა მხოლოდ bool შეიძლება იყოს → if (count > 0)
რა განსხვავებაა =-სა და ==-ს შორის?
= — ჩადე (მინიჭება) · == — ტოლია? (შედარება, აბრუნებს bool-ს)
true && false და true || false — რა გამოვა?
&& → false (ორივე უნდა იყოს true) · || → true (საკმარისია ერთი)
ქულა 8-ზე if (score >= 5) … else if (score >= 7) … — რომელი შესრულდება?
პირველი (>= 5) — if პირველივე სწორ პირობაზე ჩერდება, ამიტომ რიგს აქვს მნიშვნელობა
switch expression-ში რას ნიშნავს _?
„ყველა სხვა შემთხვევა“ — იგივე, რაც default

საშინაოს განხილვა

სლაიდი 3

წინა ლექციის საშინაო: საკუთარი თავგადასავალი. ქვემოთ არის ერთ-ერთი სწორი ამოხსნა. შენი კოდი შეიძლება სხვანაირად იყოს დაწერილი — მთავარია, მოთხოვნები სრულდებოდეს.

მოთხოვნები

  • ახალი Console App: MyAdventure. შენი სიუჟეტი (კოსმოსი, ზომბები, ფეხბურთის ფინალი — რაც გინდა)
  • მინიმუმ 2 დონის არჩევანი: პირველ არჩევანს მოსდევს მეორე (ჩადგმული if)
  • მინიმუმ 4 სხვადასხვა დასასრული
  • გამოიყენე სამივე: if / else if / else, switch ან switch expression, და ? :
  • არასწორ პასუხზე („5“ ან „ბანანი“) პროგრამა გასაგებ შეტყობინებას ბეჭდავს — ბოლო else ან _
  • თამაშის ბოლოს — ქულა: მოგება = 100, წაგება = 0, $"…"-ით დაბეჭდილი

ამოხსნა

დღის თემა: ციკლები და მასივები

1-დან 1000-მდე დაბეჭდვა 1000 ხაზია, 30 მოსწავლის ქულა — 30 ცვლადი. ასე პროგრამა ვერ გაიზრდება. დღეს ვისწავლით ციკლებს — „გაიმეორე ჩემ ნაცვლად“ — და მასივებს — ბევრი მნიშვნელობა ერთ ცვლადში. ამ ორით კი ავაწყობთ „გამოიცანი რიცხვს“ და ქულების ანალიზს.

ლექციის ბოლოს შეძლებ:

  • for, while, do-while — რომელი როდის; break და continue
  • მასივის შექმნა, ინდექსი, Length და IndexOutOfRangeException
  • მასივის გავლა for-ით და foreach-ით: ჯამი, მაქსიმუმი, ძებნა
  • რით განსხვავდება C#-ის მასივი JS-ის array-სგან

პრობლემა: დაბეჭდე 1-დან 1000-მდე

ჩვენი ახლანდელი ცოდნით — 1000 ხაზი Console.WriteLine. და თუ მერე 10 000 მოგთხოვეს?

ან: 30 მოსწავლის ქულა — 30 ცალკე ცვლადი (score1, score2…). ახალი მოსწავლე მოვიდა? კოდი თავიდან უნდა გადაწერო.

for · while · do-while — სამივე JS-იდან იცი. კომპიუტერს ყველაზე კარგად ერთი რამ გამოსდის: ერთი და იმავეს დაუღალავად გამეორება.

for: ერთადერთი განსხვავება — let → int

for (let i = 1; i <= 5; i++) {  console.log(i);}

for (int i = 1; i <= 5; i++){    Console.WriteLine(i);}
ნაწილი მნიშვნელობა
int i = 1 საიდან ვიწყებთ
i <= 5 სანამ ვაგრძელებთ
i++ რა ხდება ყოველ ჯერზე

შედეგი: 1 2 3 4 5.

1 + 2 + 3 + … + 100 = ?

სლაიდი 9

1780-იან წლებში მასწავლებელმა კლასს ეს დავალება მისცა, რომ დიდხანს დაკავებულები ყოფილიყვნენ. პატარა გაუსმა პასუხი წამებში თქვა: რიცხვები წყვილებად დააწყო — 1 + 100 = 101, 2 + 99 = 101 … × 50 წყვილი = 5050.

ჩვენ — ციკლით:

Program.cs
int sum = 0; for (int i = 1; i <= 100; i++){    sum += i;} Console.WriteLine(sum);   // 5050

sum += i — იგივეა, რაც sum = sum + i.

იმეორებს, სანამ პაროლი არასწორია. რამდენ ცდაში შეიყვანს სწორს — წინასწარ არ ვიცით.

do-while — იგივე, ოღონდ ჯერ ერთხელ აუცილებლად სრულდება, პირობა კი ბოლოს მოწმდება.

🎯 მინი-თამაში: გამოიცანი რიცხვი

სლაიდი 12
Program.cs
Console.OutputEncoding = System.Text.Encoding.UTF8; int secret = Random.Shared.Next(1, 101);   // 1..100int guess = 0;int tries = 0; Console.WriteLine("ჩავიფიქრე რიცხვი 1-დან 100-მდე!"); while (guess != secret){    Console.Write("შენი ვარაუდი: ");    guess = int.Parse(Console.ReadLine());    tries++;     if (guess < secret)    {        Console.WriteLine("მეტია ⬆");    }    else if (guess > secret)    {        Console.WriteLine("ნაკლებია ⬇");    }} Console.WriteLine($"🎉 გამოიცანი {tries} ცდაში!");

აქ ერთად არის ცვლადები, if და while:

  • Random.Shared.Next(1, 101) — შემთხვევითი რიცხვი. 101 არ შედის → 1-დან 100-მდე.
  • while — სანამ ვერ გამოიცნობ. tries++ — ცდების მთვლელი.
  • if — მინიშნება: მეტია თუ ნაკლები.
🤖 თამაშის გაუმჯობესება
დავწერე „გამოიცანი რიცხვი“ C#-ში (while, if, Random.Shared.Next, int.Parse). მეთოდები და კლასები ჯერ არ ვიცი. მინდა გავაუმჯობესო, მაგრამ თვითონ დავწერო. მომეცი 3 იდეა (მაგ. ცდების ლიმიტი, სირთულის დონე, თავიდან თამაში) და თითოეულისთვის მხოლოდ მინიშნება, მზა კოდის გარეშე. მე ვცდი და შენ შემიმოწმებ. ქართულად, 15 წლის მოსწავლისთვის.

do-while · break · continue

სლაიდი 13
🎲 კამათელი
string again; do{    int dice = Random.Shared.Next(1, 7);    Console.WriteLine($"🎲 {dice}");    Console.Write("კიდევ? (კი/არა) ");    again = Console.ReadLine();} while (again == "კი");

do-while — ჯერ ერთხელ აუცილებლად აკეთებს, პირობას ბოლოს ამოწმებს. იდეალურია მენიუსთვის და „კიდევ ითამაშებ?“-სთვის. again ციკლის გარეთ ვაცხადებთ, რომ while (…)-მა დაინახოს.

კენტები 11-მდე
for (int i = 1; i <= 20; i++){    if (i % 2 == 0)    {        continue;   // ლუწი — გამოტოვე    }    if (i > 11)    {        break;      // 11-ს მერე — გაჩერდი    }    Console.Write(i + " ");}// 1 3 5 7 9 11
  • continue — ეს ბრუნი გამოტოვე, შემდეგზე გადადი.
  • break — ციკლიდან საერთოდ გამოდი (switch-იდან უკვე იცნობ).

ნაწილი 3 · მასივები: ბევრი ყუთი ერთ თაროზე

სლაიდი 14

JS-ის array-ს ძმა — ოღონდ მკაცრი, როგორც ყველაფერი C#-ში.

მასივის შექმნა: int[] — ყუთების რიგი

სლაიდი 15
JavaScript
let scores = [9, 7, 10, 6, 8];console.log(scores[0]);      // 9console.log(scores.length);  // 5
C#
int[] scores = { 9, 7, 10, 6, 8 };Console.WriteLine(scores[0]);      // 9Console.WriteLine(scores.Length);  // 5scores[1] = 8;                     // 7 → 8
  • int[] — „int-ების მასივი“. string[] — ტექსტების, double[] — ათწილადების.
  • ინდექსი იწყება 0-დან: 5 ელემენტი → ინდექსები 0-დან 4-მდე.
  • Length — დიდი ასოთი (JS-ში length).
  • ცარიელი მასივი: new int[5] → ხუთი ნული. new string[3] → სამი ცარიელი ადგილი.

C#-ის მასივი მკაცრია

სლაიდი 16
  1. 📏 ზომა ფიქსირებულია. JS-ში push-ით ამატებდი; C#-ის მასივს push არ აქვს — 5 ადგილი სამუდამოდ 5-ია. მზარდი სიისთვის C#-ში List არსებობს — მოგვიანებით ვისწავლით.
  2. 🧱 ერთი ტიპი. JS-ში [1, "ორი", true] შეიძლებოდა. int[]-ში მხოლოდ int ჩაეტევა.
  3. 💥 საზღვრის მიღმა. JS-ში scores[10] ჩუმად აბრუნებდა undefined-ს. C#-ში პროგრამა ჩავარდება:
Console
System.IndexOutOfRangeException: Index was outside the bounds of the array.
⚠️

ყველაზე ხშირი შეცდომა: scores[scores.Length]. ბოლო ელემენტია scores[scores.Length - 1] — ინდექსი 0-დან იწყება!

მასივი + ციკლი: for და foreach

სლაიდი 17
Program.cs
string[] names = { "ნიკა", "ანა", "ლუკა" }; for (int i = 0; i < names.Length; i++){    Console.WriteLine($"{i + 1}. {names[i]}");} foreach (string name in names){    Console.WriteLine($"გამარჯობა, {name}!");}
როდის
for ინდექსი გჭირდება: ნომერი, ელემენტის შეცვლა, ყოველი მეორე
foreach უბრალოდ ყველა ელემენტი, თანმიმდევრობით
  • for-ში პირობაა i < names.Length — ნაკლებია, არა <=. სხვანაირად ბოლოს IndexOutOfRangeException.
  • foreach — JS-ის for…of-ის ძმა. ინდექსი არ არის, ამიტომ შეცდომის შანსიც.
